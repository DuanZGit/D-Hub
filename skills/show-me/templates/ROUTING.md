# 模板路由表

一句话：**先看内容的形状，再看模板的名字。** 名字相近的两个模板用错，比从零自己写还慢。

判定可以自己做（读这张表），也可以先跑脚本拿候选：

```bash
node scripts/route.mjs "讲一下 TCP 三次握手的过程"
node scripts/route.mjs --json "三个方案的优缺点对比"
```

脚本只做关键词打分，给 1 个推荐 + 2 个备选；**最终由你按形状拍板**，不要被词面骗了。

## 第一层：先判它是不是「要人动」

| 内容样子 | 走 | 判据 |
|---|---|---|
| 人要拖、要点、要演一段过程、要看远近 | `interactive-scenes.html` | 不操作就不往下走 |
| 只要一个自己动的背景 | `motion-16.html` | 打开就自己动，和人无关 |
| 都不用 | 往下看第二层 | |

`interactive-scenes` 里 13 组按四类分：A 直接操作（引力场 / 流场画笔 / 点击涟漪 / 参数实验台）、
B 情景模拟（数据流转 / 路口信号 / 雷达扫描 / 传播扩散）、C 动画叙事（流程链 / 形态演变 / 时间回放）、
D 空间距离（景深视差 / 隧道穿梭）。

## 第二层：判它是「讲」还是「摆」

- **摆**（已经算完，只差让人看清）→ 展示台 `showcase-*.html`
- **讲**（要带人从不懂到懂）→ 讲法骨架 `skeleton-*.html`

### 摆：四类不重叠

| 内容 | 模板 | 交互 |
|---|---|---|
| 排名 / 倍数 / 占比，结论已定 | `showcase-board.html` | 方块数即数值，基准虚线 |
| 有因果或时间顺序 | `showcase-narrative.html` | 时间轴播放，每幕重放 |
| 有参数可调、结果跟着变 | `showcase-dashboard.html` | 滑杆 → 实时重算 |
| 谁连着谁，节点细节多 | `showcase-topology.html` | 点节点出详情，请求沿链走 |

### 讲：四套主题按语气分

| 语气 | 模板 | 长相 |
|---|---|---|
| 参数清单 / 产品说明 / 系统状态 | `skeleton-tech.html` | 终端仪表盘：状态条 + 编号导轨 + 栅格卡 |
| 概念疏解 / 观点短文 | `skeleton-ink.html` | 书页：竖排书脊 + 正文缩进 |
| 视觉冲击型介绍 / 报告 | `skeleton-mag.html` | 杂志封面：首字下沉 + 三栏 + 色块 |
| 情绪 / 留白 / 一句话观点 | `skeleton-zen.html` | 窄栏 + 大间距 + 细线 |

## 第三层：不属于上面任何一类

| 内容 | 走哪 | 为什么不进模板 |
|---|---|---|
| 一组数字要画成实物（占比、预算、漏斗） | **`minicharts` 技能** | 它自带 54 种画法和校验脚本，模板给不了 |
| 要用户勾选 / 复制指令 | `~/.pi/agent/templates/decision-deck-template.html` | 决策台的交互逻辑在它的脚本里，不要自己抄 |
| 三五个节点的关系图 / 流程图 | `diagram`（D2）或 `svg-mcp` | 见 SKILL.md「图：工具与尺寸」 |

## 反例（选错比不选更贵）

- 「讲一下三次握手」→ 走 `skeleton-ink`（概念），**不是** `showcase-topology`（拓扑是摆已有结构，不是讲过程）。
- 「我们花了多少钱」→ 走 `minicharts`（画成硬币），**不是** `showcase-board`（方块榜会像报表）。
- 「两个方案哪个好」→ 走决策台，**不是** `skeleton-ink`（那是讲道理，不是让人拍板）。
- 「系统里请求怎么走」→ 走 `showcase-topology` 或图，**不是** `interactive-scenes`（除非要演给人看请求一步步流）。

## 套用与交付

模板现在是**外链库**：文件里写 `<script src="assets/three.min.js"></script>`，所以模板本身只有 20–38KB，能一次读完。

1. `cp templates/<选中的>.html explain/<主题>.html`
2. 改数据区与文案，保留动效层；每个骨架文件头有「几处要改」，先读那 30 行
3. **交付前必须 bundle**（产出要单文件自包含）：

```bash
node scripts/bundle.mjs explain/<主题>.html
```

不 bundle 就直接发出去，页面在别的目录打开时 Three.js 会 404，动效全黑。
