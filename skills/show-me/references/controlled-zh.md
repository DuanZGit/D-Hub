# 受控语言（中文落地版）

来源是 **ASD-STE100**：航空维修手册用的受控英语。它把词汇表和句式压到极窄，
代价是死板，换来的是一眼读懂 —— 飞机维修工在噪声和压力下也必须看懂。

英文原版太严（连时态和词性都管），日常用「**80% 版本**」就够：
只保留下面 8 条里最见效的 3 条 —— **句长、一句一意、一词一义**。

## 8 条硬规则

1. **一句只说一件事。** 中文超过 25 字就拆句。
2. **主动语态。** 「被判定为异常」→「系统判定它异常」。
3. **一词一义。** 同一个东西从头到尾用同一个词，不要换同义词（模型 / LLM / 大语言模型 混用 = 读者多花三次力气）。
4. **术语第一次出现给白话解释**，之后固定用那个词。
5. **删空转词**：值得注意的是 / 综上所述 / 不仅…而且 / 众所周知 / 一定程度上 / 在某种意义上。
6. **不嵌套从句。** 把「由于 A，导致在 B 的情况下出现 C」拆成三句。
7. **数字给单位和口径。**「延迟很低」→「中位延迟 12ms，p99 90ms」。
8. **每段首句就是结论**，后文只做支撑。

## 反例

> 原文：**「值得注意的是，该机制在一定程度上通过缓存层对下游请求进行了削峰处理」**
>
> 改后：「缓存层挡住突发流量。峰值的请求先排队，后端按自己的速度取。」

> 原文：**「由于模型在推理阶段存在显存瓶颈，导致在长上下文场景下吞吐出现明显下降」**
>
> 改后：「长上下文吃显存。显存装不下时，模型一次只能算更少的请求，吞吐就掉下来。」

## 怎么用

- 直接对模型说：「用受控语言重写这段，一句一件事，不要空转词。」
- 想更严：「用 ASD-STE100 重写」；想保留一点文气：「走到 ASD-STE100 的 80%」。
- 中文内容优先用上面 8 条，不要照搬英文标准的词性规则 —— 那是为英语语法设计的。

## 边界

受控语言管的是**读起来费不费力**，不管内容对不对。
一份受控语言写出来的废话仍然是废话：先把结构理清，再压句子。
