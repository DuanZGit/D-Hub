# 视觉反 slop（L3/L4）

AI 做的解释页有很强的默认味，一眼能认出来。这份清单是「像人做的」和「像 AI 做的」的分界。

**总判据：把内容换成别的话题，这套设计几乎不用改 —— 就是太通用。**
颜色、留白、图的形态应当跟正在讲的东西有关，而不是从上一次的模板抄过来。

## 仪表盘件，搬到解释页就是错的

| 别做 | 为什么 | 换成 |
|---|---|---|
| KPI 大数字卡（大数 + 标签 + 彩色边） | 监控用，不是解释用 | 把这个数量写进一句正文或图注 |
| 指标网格（一排 3–4 个统计卡） | 数字脱离了上下文 | 在叙述里引入，需要时标在图上 |
| 状态徽章（绿/黄/红胶囊） | 编码的是系统运维状态 | 用正文说清「正常长什么样」 |
| 满页圆角卡片 + 阴影 | 用容器代替结构 | 留白 + 字号 + 字重来分层 |
| 彩色 callout（蓝「要点」框、绿「提示」框） | 切断了阅读流 | 写成一句有分量的正文 |

## 通用 AI 视觉，逐条避开

- **默认蓝紫**：#3B82F6 配 #8B5CF6。换成和内容相关的色（数据密集用低饱和中性 + 一个强调色；过程类用暖冷对比表示前后）。
- **唯一 system-ui 字体**：本机不许外链字体（自包含），所以靠**字体栈内的对比**制造层次 —— 正文可用衬线栈 `Georgia,"Songti SC","Noto Serif CJK SC",serif`，标签和数字用等宽栈，标题加大字号与负字距。同一页里两种气质就够，别堆。
- **发光阴影、呼吸脉冲、渐变描边**：装饰性，不传递信息。删掉，把动效留给「状态变化」那一处。
- **emoji 当标题或列表符号**：用字重和留白分段。
- **巨型 hero**：大字号居中 + 渐变底，占掉一屏什么也没讲。第一屏就该出现内容或第一张图。

## 排印

- 中文正文 18–20px，行高 1.5–1.7，每行 30–38 个汉字（对应西文 60–75 字符）。
- 三档层级要能一眼分辨：主（洞察本身）／次（定义、上下文）／三（细节、边界情况）。第三档放到边注或折叠里，别和主线同权重。
- 代码用等宽，公式用 KaTeX 或纯 CSS 排版，别用图片贴公式。

## 文字本身也是设计

产出页里的每一句话都在决定它像不像人写的。

| 别写 | 改成 |
|---|---|
| 破折号堆砌（一句话三个「——」） | 拆成两句 |
| 「不是 X，而是 Y」的否定翻转 | 直接说 Y；除非要纠正读者真实存在的误解 |
| 「本文将探讨」「接下来我们看看」 | 直接开始讲 |
| 三元形容词堆（「更快、更稳、更可靠」） | 留一个最准的，给数值或场景 |
| 空洞动词（赋能、助力、重塑、颠覆） | 换成具体动作 |
| 结尾「总而言之」大总结 | 收在一个具体后果或一个仍待回答的问题上 |
| 格言式镜像句（「慢即是快」） | 给出机制 |
| 悬念标题（「你可能不知道的第三点」） | 描述或直接提问 |

## 自查

交付前扫一遍产出，逐条问：这一处换成别的话题还成立吗？成立就删或改。删掉的装饰不需要补别的东西，留白本身就是结构。
