# 教学法（L3/L4）

解释页的目的只有一个：让读者理解一个东西怎么运作。下面这些规律决定它成不成，与用多少技术无关。

## 三级信息层级

**主**：那个洞察和支撑它的论证，占最大视觉权重。
**次**：定义、上下文、相关概念，正常正文权重。
**三**：技术细节、推导、边界情况，放边注、折叠块或小字。

读者不读一个字也应该能看出这三档的差别。做不到就是各级权重太接近。

## 视觉编码

- **位置和长度是最准的通道**，把最重要的量交给它们。面积和角度会让人低估。
- **颜色只编码类别或高亮**，别用它单独承载数量（色盲 + 深浅差不可靠）。
- **冗余编码**：颜色 + 位置/形状同时表达同一件事，可读性立刻提高。
- 同一变量全场同一颜色。第一张图里蓝色代表学习率，后面每张图都得是。

## 交互模式，按需选

| 模式 | 什么时候用 |
|---|---|
| 按需细节 | 补充信息会打乱叙述节奏 |
| 可探索 | 概念本身有一个参数空间值得读者自己摸 |
| 联动视图 | 同一份数据有两种都合理的表现 |
| 滚动叙事 | 解释有天然的先后顺序要逐层揭开 |
| 过渡动画 | 「从状态 A 到状态 B 中间发生了什么」本身是重点 |

一个页面里两种模式够了。全都用上就是仪表盘。

## 五条硬规矩

1. **夸张以求清晰。** 默认参数要让现象明显可见。讲黏度就把黏度调大，讲两种方法的差异就选它们明确分歧的参数。教学清晰度优先于物理真实；读者能调小，看不出就学不到。
2. **打开就有东西看。** 没有空白画布，没有「点击粒子开始」，没有等待落定的点阵。默认状态本身就在演示那个现象。
3. **慢到能跟得上。** 读者要看清「场如何响应」「路径如何转向」。拿不准就更慢；想快的人自己会调。
4. **约定全局统一。**  半径画成虚线圆就每张图都虚线圆；公式里的变量着色和图中一致。不一致等于让读者每张图重学一次视觉语言。
5. **循环动画干净复位。** 重开时回到初始状态，不继承上一轮的累积值或残影。

## 一屏一个意思

自播放页 5–9 个 scene；交互页每个小节只承担一个论点。塞满就没人重读。超了拆两页，宁可两页各讲透一件事。
