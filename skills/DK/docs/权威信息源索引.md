# 权威信息源索引

> 让每个日常知识都有科学性的支撑

## 状态说明

- ✅ 可用 - 爬取成功，方法已固化（自动记录在 `config/success/`）
- ⚠️ 部分可用 - 爬取成功但内容有限
- ❌ 不可用 - 爬取失败，已尝试多种方法
- 🔄 待测试 - 尚未测试

## 固化机制

爬取成功后，调用脚本自动固化：

```bash
# 固化爬取方法
bash scripts/knowledge-fix.sh <源名> <标题> <URL> <方法> [raw文件路径]

# 固化后自动创建:
# - config/success/<源名>.sh  → 可复用的爬取脚本
# - raw/领域/日期-源名.md    → 原始资料存档
```

**固化后的爬取方法**会：
1. 自动保存在 `config/success/` 目录下
2. 查询时自动优先使用该固化方法
3. 方法不依赖特定平台/Agent，纯 shell/python

**支持的固化方法**：
- `curl-grep` — curl + 正则提取（最轻量）
- `curl-bs4` — curl + BeautifulSoup（推荐）
- `jina` — Jina Reader API（无需JS引擎）
- `playwright` — Playwright浏览器（虚拟机）

### 爬取方法

1. **ctx_fetch_and_index** - 直接爬取首页
   - 适用：大部分网站首页
   - 优点：简单、快速
   - 缺点：无法爬取需要JavaScript的页面

2. **ctx_search** - 搜索已爬取内容
   - 适用：已爬取的页面内容
   - 优点：可以快速查找关键词
   - 缺点：只能搜索已爬取的内容

3. **requests + BeautifulSoup** - 直接HTTP请求
   - 适用：wikiHow等静态页面
   - 优点：轻量、可控、不需要JS引擎
   - 缺点：无法处理JS渲染的页面

4. **Playwright (虚拟机)** - 完整浏览器
   - 适用：JS渲染页面、需要搜索的网站
   - 优点：功能最全、可执行JS
   - 缺点：需要虚拟机环境

### 失败处理

1. **HTTP 412错误** - 反爬机制
   - 解决：换平台（如国家卫健委换中国疾控中心）

2. **HTTP 404错误** - 页面不存在
   - 解决：检查URL、搜索其他页面、换平台

3. **JavaScript渲染** - 需要JS执行
   - 解决：Playwright虚拟机、ctx_fetch_and_index、换平台
