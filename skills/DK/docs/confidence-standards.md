# 置信度评级标准

## 高置信度

满足以下所有条件：
- 多方权威来源一致（至少 2 个独立权威机构）
- 有系统综述/Meta 分析支持
- 国家标准/指南明确规定
- 无显著争议

**示例**：中国居民膳食指南推荐量、WHO 安全摄入标准、GB 食品添加剂标准

## 中置信度

满足以下任一条件：
- 单一权威来源支持
- 有专家共识但证据有限
- 实践经验广泛但缺乏严格 RCT
- 存在轻微争议但主流观点一致

**示例**：某种食物特定健康功效、非标准化的烹饪技巧效果

## 低置信度

满足以下任一条件：
- 单一自媒体/经验分享
- 存在明显争议
- 过时信息或无科学验证
- 仅为理论推测，无实践验证

**示例**：网络流传的"偏方"、未经证实的养生说法

## 应用规则

1. **必须标注**：每条非事实性结论必须标注置信度
2. **来源透明**：低/中置信度内容必须注明信息来源
3. **边界清晰**：明确结论的适用范围和例外情况
4. **动态更新**：新证据出现时重新评级
