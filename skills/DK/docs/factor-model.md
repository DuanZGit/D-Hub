# 烹饪化学反应因子模型

> 将烹饪视为可控的化学反应系统：食材因子 × 烹饪方式因子 × 调味因子 → 可预测的成品结果。

## 因子的判据（三问筛）

> 2026-09-26 订立。起因：一次晚餐合集的因子分析中，约 30% 的内容是「看起来像因子」的填充物——术语正确但不改变操作，或数字是编的。

一条内容要被称为「因子」，必须过三问：

1. **删掉它，操作会不会变？**
   不会 → 它不是因子，是装饰。删掉，或明确降级为「解释」。
2. **能不能迁移到别的菜？**
   能 → 是有价值的**教育性解释**（如「含水 90% → 先蒸发才上色」可迁移到所有菌菇）。
   不能，且操作也不变 → 纯装饰，删。
3. **数字有出处吗？**
   有 → 标出来源（书名 / 文献 / 实测日期）。
   没有 → **必须标「经验估计」**，禁止与有出处的数字混排而不加区分。

### 三类标签（强制标注）

| 标签 | 含义 | 例 |
|------|------|-----|
| `[出处]` | 有书 / 文献 / 权威来源 | 美拉德 140–165°C《料理实验室》 |
| `[实测]` | 用户真实厨房验证过 | 小火 120–150°C 炒蛋黄 [实战检验 2026-08-04] |
| `[经验]` | 厨房共识或推算值，**无硬来源** | 「每面 60 秒」（薄切推算，需按实际微调） |

### 禁止的写法

- ❌ 给精确数字但不标来源，让读者以为它与有出处的数字同等可靠
- ❌ 把宽分布伪装成窄区间（例：维 C 焯水保留率文献范围 **32–97%**，写成「70–80%」）
- ❌ 用精确温度区间包装非温度驱动的现象（例：把乳化写成「80–95°C」——乳化实际由搅拌与表面活性剂驱动）
- ❌ 同一道菜给两套互斥方案（例：一处「分两批煎」、一处「铺满一次煎完」）
- ❌ 把结论正确但机理编错的解释当因子（例：「不锈钢导热不如铸铁」——实际铝芯夹层正是为了均热；「手撕断面不规则所以破损少」——自相矛盾）

## 食材因子（Reactants）

每条食材记录其可量化特性：
- **结构因子**：细胞壁厚度、纤维密度、蛋白质含量、淀粉含量、脂肪含量
- **化学因子**：pH 值、水分活度、还原糖含量、氨基酸组成、挥发油含量
- **热力学因子**：变性温度、糊化温度、焦糖化起始温度、热降解阈值

## 烹饪方式因子（Reaction Conditions）

每种烹饪方式定义其参数空间：
- **传导介质**：油、水、蒸汽、空气
- **温度范围**：如炒 200–300°C，蒸 100°C，炖 85–95°C
- **时间尺度**：秒级（炒）/ 分钟级（蒸）/ 小时级（炖）
- **热力学特征**：传导/对流/辐射，升温速率，热惯性

## 化学反应因子（Reaction Pathways）

在给定条件下哪些反应被激活：
- **美拉德反应**：140–165°C，氨基酸 + 还原糖 → 香气 + 褐变
- **焦糖化反应**：160–180°C，糖类 → 焦糖风味 + 色泽
- **蛋白质变性**：40–80°C，空间结构破坏，质地改变
- **淀粉糊化**：60–70°C，吸水膨胀，增稠
- **胶原蛋白水解**：85–95°C 长时间，结缔组织 → 明胶
- **渗透压效应**：盐浓度梯度 → 细胞失水/入味
- **热降解**：>120°C 挥发物散失，MSG 降解，色素破坏

## 调味因子（Catalysts & Modifiers）

- **时机因子**：何时加入（反应窗口）
- **浓度因子**：用量（反应程度控制）
- **协同因子**：组合效应（如酱油 + 糖 → 增强美拉德）

## 输出可预测性

通过因子组合，可预测：
- **质地**：脆/嫩/烂/糊
- **色泽**：翠绿/金黄/褐红/雪白
- **风味**：鲜/香/酸/麻/辣
- **营养保留率**：维生素 C、B 族等热敏营养素保留比例
- **安全边界**：油烟温度、丙烯酰胺生成风险、杂环胺风险

## 因子化知识库

**食材页面**：
- 结构因子：细胞壁厚度、纤维密度
- 化学因子：pH、水分活度、关键成分
- 热力学因子：变性温度、降解阈值
- 最佳反应条件：推荐烹饪方式 + 温度 + 时间
- 禁忌条件：什么条件下会变差

**烹饪方式页面**：
- 传导介质和温度范围
- 激活的反应路径
- 适用食材因子范围
- 不适用食材因子范围

**调味料页面**：
- 反应窗口（温度-时间曲线）
- 协同/拮抗效应
- 降解产物和风险

**食谱页面**：
- 输入：食材因子组合
- 条件：烹饪方式因子 + 调味因子时序
- 输出：预期质地、色泽、风味、营养保留率
- 验证：可复现性记录
