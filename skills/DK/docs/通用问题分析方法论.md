# 通用问题分析方法论

> 让每个日常知识都有科学性的支撑

## 核心逻辑

```
原始问题 → 领域识别 → 问题分解 → 信息源选择 → 查询执行 → 底层机理分析 → 答案生成
```

## 步骤1：问题分类

任何问题都属于某个领域，不同领域对应不同信息源：

| 领域 | 典型问题 | 首选信息源 |
|------|----------|------------|
| 食品安全 | 食物保存、冰箱清洁 | FDA、USDA、国家标准 |
| 营养健康 | 饮食、营养素 | 中国营养学会、WHO |
| 疾病预防 | 症状、预防 | CDC、WHO、医院 |
| 家电使用 | 清洁、维修 | 制造商官网、家电研究院 |
| 家居清洁 | 清洁方法、消毒 | 清洁公司、消费者报告 |
| 育儿 | 婴儿护理、发育 | 儿科协会、WHO |
| 运动健身 | 锻炼、恢复 | 运动医学协会、研究文献 |
| 化妆护肤 | 皮肤护理、成分 | 皮肤科协会、FDA |

## 步骤2：问题分解（最核心）

把原始问题分解成3-5个可查询的科学子问题。

### 食材/做法类的强制拆解

再额外拆成下面四层：

1. **营养层** - 蛋白质、脂肪、碳水、维生素、矿物质、膳食纤维
2. **成分层** - 主要风味分子、苦味/涩味/腥味来源、挥发性香气
3. **反应层** - 美拉德、焦糖化、蛋白质变性、淀粉糊化、氧化、脂溶/水溶迁移
4. **搭配层** - 互补营养、互补口感、是否容易出水、发柴、发苦、发腥

### 分解公式

```
原始问题 = [事物] + [动作] + [目标]
```

### 分解模板

1. **[事物]是什么？** - 物理/化学/生物特性
2. **为什么要[动作]？** - 科学原理/必要性
3. **[动作]的科学方法？** - 具体步骤/依据
4. **如何达到[目标]？** - 效果评估/验证
5. **如何预防？** - 长期解决方案

### 示例

| 原始问题 | 事物 | 动作 | 目标 |
|----------|------|------|------|
| 冰箱发霉如何清洗 | 霉菌 | 清洗 | 消除霉菌 |
| 番茄怎么做好吃 | 番茄 | 烹饪 | 好吃 |
| 膝盖疼怎么办 | 膝盖 | 治疗 | 止疼 |
| 如何防止婴儿湿疹 | 婴儿皮肤 | 预防 | 湿疹 |
| 跑步后如何恢复 | 肌肉 | 恢复 | 减少酸痛 |

## 步骤3：信息源映射

根据领域和问题类型，选择对应的信息源。

### 信息源类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 政府机构 | 权威、标准、法规 | 食品安全、公共卫生 |
| 学术机构 | 科学、严谨、前沿 | 疾病机理、科学研究 |
| 学术数据库 | 文献、研究、证据 | 需要科学依据 |
| 行业协会 | 专业、实用、规范 | 家电使用、烹饪方法 |
| 制造商 | 直接、具体、官方 | 产品使用、清洁维护 |
| 营养数据库 | 成分、含量、搭配 | 食材与营养判断 |
| 菜谱数据库 | 食谱、口味、成功率 | 做法与搭配验证 |
| 消费者报告 | 测试、比较、建议 | 产品选择、使用建议 |

### 映射规则

```
如果是"如何做" → 查制造商/行业协会/菜谱数据库
如果是"为什么" → 查学术机构/学术数据库
如果是"是否安全" → 查政府机构
如果是"哪个好" → 查消费者报告
如果是"怎么搭配" → 查营养数据库 + 食品化学 + 菜谱数据库
```

## 步骤4：查询执行

从选定的信息源获取实际知识。

### 查询策略

1. **直接搜索** - 在信息源网站搜索关键词
2. **查找文档** - 搜索官方指南、说明书、PDF
3. **查找研究** - 在学术数据库搜索相关研究
4. **查找评测** - 在消费者报告搜索评测
5. **查营养/化学表** - 先用数据库确认食材成分，再讨论搭配和反应

### 关键词技巧

```
中文：事物名 + 动作 + 方法/指南/步骤
英文：[thing] + [action] + method/guide/step
```

## 步骤5：答案整合

从多个来源整合信息，生成有科学支撑的答案。

### 固定输出结构

对食材/菜品类问题，最终回答必须按这个顺序输出：

1. `已触发daily knowledge技能`
2. 直接结论
3. 量化营养数据
4. 物理/化学反应或烹饪原理
5. 引用源
6. 不确定项说明

### 整合原则

1. **多源验证** - 至少2个权威来源确认
2. **优先级** - 政府机构 > 学术机构 > 营养/化学数据库 > 行业协会 > 制造商 > 菜谱实证
3. **时效性** - 优先最新信息
4. **适用性** - 考虑本地实际情况
5. **底层逻辑** - 每个食材搭配要能解释“为什么好吃/为什么不行”

## 实际应用示例

### 示例1：番茄怎么做好吃？

**步骤1：问题分类** - 食品/烹饪

**步骤2：问题分解**：
1. 番茄的营养特性是什么？
2. 番茄在什么温度下营养流失最少？
3. 番茄搭配什么食材营养更均衡？
4. 番茄的最佳烹饪方式是什么？

**步骤3：信息源选择**：
- 营养特性 → 中国营养学会、USDA FoodData Central
- 烹饪方式 → 中国烹饪协会、食品科学研究

**步骤4：查询执行**：
- 搜索"番茄 营养成分"
- 搜索"番茄 烹饪温度 维生素C"
- 搜索"番茄 食材搭配 营养"

**步骤5：答案生成**：
- 基于营养学研究给出建议
- 引用权威来源

### 示例2：膝盖疼怎么办？

**步骤1：问题分类** - 健康/医疗

**步骤2：问题分解**：
1. 膝盖疼的可能原因是什么？
2. 什么情况下需要就医？
3. 家庭护理方法有哪些？
4. 如何预防膝盖疼？

**步骤3：信息源选择**：
- 症状原因 → 中国疾控中心、WHO
- 就医指南 → 医院官网、医学协会
- 家庭护理 → 运动医学协会、康复机构

**步骤4：查询执行**：
- 搜索"膝盖疼 原因 症状"
- 搜索"knee pain causes treatment"
- 搜索"膝盖疼 家庭护理"

**步骤5：答案生成**：
- 区分需要就医和可自行处理的情况
- 给出家庭护理建议
- 引用医学权威来源

### 示例3：如何防止婴儿湿疹？

**步骤1：问题分类** - 育儿/健康

**步骤2：问题分解**：
1. 婴儿湿疹的原因是什么？
2. 什么因素会诱发湿疹？
3. 预防措施有哪些？
4. 如何护理湿疹皮肤？

**步骤3：信息源选择**：
- 湿疹原因 → 儿科协会、WHO
- 预防措施 → 儿科医院、育儿指南
- 皮肤护理 → 皮肤科协会、医学研究

**步骤4：查询执行**：
- 搜索"婴儿湿疹 原因 预防"
- 搜索"infant eczema prevention"
- 搜索"婴儿皮肤护理 指南"

**步骤5：答案生成**：
- 基于儿科医学给出预防建议
- 引用权威育儿指南

## 快速检查清单

在回答任何问题前，检查：

- [ ] 这个问题属于什么领域？
- [ ] 可以分解成哪些科学子问题？
- [ ] 每个子问题应该去哪类信息源查询？
- [ ] 是否从至少2个权威来源获取了信息？
- [ ] 答案是否有科学依据支撑？
- [ ] 是否引用了权威来源？
