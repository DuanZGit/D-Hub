# 食谱生成指南 - Agent 用这个来生成任意菜品的食谱

## 核心原理：烹饪化学反应因子模型

当用户问一道菜怎么做时，Agent 应该将烹饪视为**可控的化学反应系统**：

```
食材因子 × 烹饪方式因子 × 调味因子 → 可预测的成品结果
```

### 因子分析步骤

1. **食材因子分析（Reactants）**
   - 结构因子：细胞壁厚度、纤维密度、蛋白质/淀粉/脂肪含量
   - 化学因子：pH、水分活度、还原糖、氨基酸、挥发油
   - 热力学因子：变性温度、糊化温度、降解阈值

2. **烹饪方式因子匹配（Reaction Conditions）**
   - 传导介质：油/水/蒸汽/空气
   - 温度范围：如炒 200–300°C，蒸 100°C，炖 85–95°C
   - 时间尺度：秒级（炒）/ 分钟级（蒸）/ 小时级（炖）
   - 热力学特征：传导/对流/辐射，升温速率，热惯性

3. **调味因子编排（Catalysts & Modifiers）**
   - 时机因子：何时加入（反应窗口）
   - 浓度因子：用量（反应程度控制）
   - 协同因子：组合效应

4. **反应预测与验证**
   - 预测成品：质地、色泽、风味、营养保留率
   - 标注安全边界：油烟温度、有害物质生成风险
   - 提供可复现参数：精确温度、时间、用量

### 传统流程（在因子模型框架内执行）

1. **识别菜品类型**：荤菜/素菜/汤品/主食/甜点
2. **确定烹饪方式**：炒/蒸/煮/炖/煎/炸/烤/凉拌
3. **查询相关原理**：从知识库获取科学原理
4. **生成完整食谱**：融合因子模型生成详细步骤
5. **标注营养信息**：提供每份营养成分
6. **提示常见错误**：避免失败的关键点

## 烹饪方式速查

### 炒（200-300°C，大火快炒）
**适用**：蔬菜、肉片、海鲜
**原理**：美拉德反应产生香味，快速锁住水分
**要点**：
- 锅热油热，冒烟前下菜
- 大火快炒，不超过3分钟
- 食材切小均匀
- 先炒硬的后炒软的

### 蒸（100°C，水蒸气加热）
**适用**：鱼、蛋、蔬菜、面食
**原理**：保留营养最多（90%以上），不产生有害物质
**要点**：
- 水开后再放食材
- 大火蒸制，中途不开盖
- 蒸鱼8-10分钟，蒸蛋15分钟

### 煮（100°C，水传导）
**适用**：汤类、粥、面条
**原理**：水溶性维生素会流失到汤中，但汤可回收
**要点**：
- 肉类冷水下锅去血沫
- 蔬菜热水下锅保色
- 汤要一起喝

### 炖（85-95°C，小火慢炖）
**适用**：肉类、骨头、根茎蔬菜
**原理**：胶原蛋白水解成明胶，肉质软烂
**要点**：
- 大火烧开，小火慢炖
- 中途不加冷水
- 盐最后15分钟放（早放盐提高渗透压，降低风味扩散效率）

### 煎（150-200°C，油脂传导）
**适用**：鱼、肉、蛋、豆腐
**原理**：表面焦化形成美拉德反应外壳，锁住水分
**要点**：
- 热锅冷油防粘
- 不要频繁翻动，等定型再翻
- 中火慢煎

### 炸（170-190°C，高温油）
**适用**：肉类、蔬菜、面食
**原理**：快速脱水焦化，形成酥脆外壳
**要点**：
- 油温要够（筷子冒泡）
- 分次炸：第一次炸熟，第二次炸脆
- 炸完沥油

### 烤（150-250°C，热辐射）
**适用**：肉类、面包、蔬菜
**原理**：美拉德反应+焦糖化反应
**要点**：
- 预热烤箱
- 肉类烤前回温，烤后静置
- 用锡纸包裹减少有害物质

### 凉拌（常温，不加热）
**适用**：蔬菜、豆制品、熟肉
**原理**：保留营养100%，调味料渗透入味
**要点**：
- 食材洗净
- 先加盐杀水
- 冷藏后更佳

### 焯水（100°C，短时间水煮）
**适用**：蔬菜、肉类预处理
**原理**：去草酸、去农残、去腥
**要点**：
- 水开下锅，加盐油保色
- 蔬菜30秒-2分钟
- 肉类冷水下锅去血沫

## 食材处理速查

### 肉类通用
```
去腥：冷水浸泡30分钟，加料酒姜片焯水
嫩滑：加淀粉、蛋清腌制15分钟
切法：逆纹切，口感更嫩
焯水：冷水下锅，煮开撇沫
保存：冷冻可保存3个月，冷藏3天
```

### 鱼类通用
```
去腥：盐搓洗，料酒姜片腌制10分钟
处理：去鳞去内脏去鳃，斜刀切花刀
蒸制：水开后上锅，8-10分钟
保存：冷藏1-2天，冷冻1个月
```

### 蔬菜通用
```
清洗：先洗后切，减少营养流失
焯水：水开下锅，加盐油保色，30秒-2分钟
炒制：大火快炒，保持翠绿
保存：冷藏3-5天，叶菜类尽快食用
```

### 豆腐通用
```
定型：盐水浸泡30分钟
去腥：焯水2分钟
煎制：热锅冷油，不要急着翻面
保存：冷藏2-3天，冷冻可保存1个月
```

### 蛋类通用
```
煮蛋：冷水下锅，水开后6分钟（溏心）/10分钟（全熟）
炒蛋：大火快炒，蛋液凝固即出锅
蒸蛋：蛋水比1:1.5，中火蒸12-15分钟
保存：冷藏2周，避免与气味重的食物放一起
```

### 海鲜通用
```
去腥：料酒姜片腌制，葱姜蒜爆香
烹饪：大火快炒，避免过老
蒸制：水开后上锅，视大小3-8分钟
保存：冷藏1-2天，建议当天食用
```

## 调味速查

### 基础调味
```
盐：提鲜，炒肉变色凝固后放，炒青菜出锅前几秒放，煲汤最后15分钟放
糖：中和酸味，提鲜，炒糖色上色
酱油：生抽油热后沿锅边淋入激发锅气，老抽中途加入上色
醋：第一次热油时沿锅边烹入留香，第二次出锅前点几滴留酸
料酒：酒精挥发带走腥味
```

### 增鲜调味
```
蚝油/味精/鸡精：出锅前放，余温翻匀。MSG 120°C以上开始降解，久煮发苦
```

### 香料
```
姜：冷油时先下，低温慢煸（80-120°C）出香，最耐热
蒜：姜出香后再下，150-180°C易褐变，金黄即临界点
葱：快出锅时最后放，含硫挥发物沸点低，久煮挥发
花椒：出锅前放，羟基-alpha-山椒素热不稳定，久煮麻味消失
八角/桂皮：炖肉增香
干辣椒：辣味，根据口味调整
香叶：炖肉增香，去腥
```

### 粉类调味
```
白胡椒粉：出锅前放，胡椒碱和挥发油久煮散失
花椒粉：出锅前放，热不稳定，久煮只剩苦
五香粉/十三香：加水前用油煸一下，挥发油需油爆提取
孜然粉：肉快熟时撒，高温1-2分钟即释放香气，不宜久烤
水淀粉（勾芡）：出锅前淋入，边淋边搅。淀粉60-70°C糊化，早放沉底结块
```

### 万能酱汁
```
糖醋汁：糖3:醋2:生抽1:料酒1
红烧汁：生抽2:老抽1:料酒2:糖1
蒜蓉汁：蒜末+生抽+醋+糖+香油
凉拌汁：生抽+醋+蒜+辣椒油+糖
鱼香汁：糖2:醋2:生抽1:料酒1:豆瓣酱1
宫保汁：糖2:醋1:生抽1:料酒1:淀粉水
```

### 调味原则
```
1. 分层调味：基础味（盐糖）→ 风味味（酱油醋）→ 香味味（葱姜蒜）
2. 科学时机：
   - 盐：缩短与食材接触时间，减少渗透压失水（炒肉变色后/青菜出锅前/煲汤最后15分钟）
   - 酱油：高温激发美拉德反应产生锅气（油热后沿锅边淋入）
   - 醋：第一次高温挥发留香，第二次出锅前留酸
   - 增鲜剂：120°C以上降解，出锅前放
   - 香料：出锅前放保留挥发香气；油爆法提取脂溶性风味
3. 适量调味：宁少勿多，逐步添加
4. 平衡调味：酸甜苦辣咸，相互衬托
```

## 食谱生成模板

> **通用原则**：模板按**烹饪方式**分类（不是按荤/素），因为因子模型的核心是"烹饪方式因子"。  
> 多段烹饪的菜（如糖醋排骨=腌→炸→裹汁）以**主烹饪方式**选模板，在步骤中补充其他烹饪段。

### 模板通用结构

每个模板固定包含 6 个部分（缺一不可，反模式禁止直接输出空字段）：

```
【食材】→【因子分析】→【步骤(含原理)】→【预期成品】→【安全边界】→【成功关键/常见错误】
```

---

### 1. 炒制模板（200–300°C，油传导，秒~分钟级）

**适用**：肉片/肉丝、蔬菜、蛋、豆制品、海鲜；炒饭炒面等主食（主料换成淀粉类）
**不适用**：大块肉（内部熟不了）、厚根茎蔬菜（传导不够）

```
【菜品名】- XX版

【食材】
主料：[食材+用量，如 猪里脊200g / 青菜300g / 米饭2碗]
腌料（肉类）：[料酒/淀粉/蛋清/生抽]
调味料：[生抽/盐/糖/醋/增鲜剂]
辅料：[葱姜蒜/干辣椒/花椒]

【因子分析】
- 食材因子（按主料填写）：蛋白质含量/水分含量/纤维密度/是否易熟
- 烹饪方式因子：炒（200–300°C，秒~分钟级），激活美拉德反应 + 表面蛋白快速变性；淀粉类激活糊化
- 调味因子：生抽沿锅边淋入（140°C+ 美拉德锅气）；盐缩短接触时间（减少渗透压失水）；增鲜剂出锅前放（>120°C 降解）；勾芡出锅前淋入（60–70°C 糊化）

【步骤】
1. 预处理：[切配方式 + 腌制/焯水]
   【原理】逆纹切切断肌纤维（嫩）；淀粉蛋清包裹锁水；焯水去草酸
2. 热锅冷油，[爆香顺序：姜→蒜→主料]
   【原理】油温>200°C 表面快速焦化锁水；姜耐热先下，蒜易褐变金黄即出
3. 主料下锅：[炒制动作+时间]
   【原理】大火快炒，细胞壁部分破裂保持脆度；肉类变色即熟
4. 调味：[按时机依次加入]
   【原理】参考 [[调味料下锅时机]]：生抽沿锅边、盐最后、增鲜剂出锅前
5. 收尾：[勾芡/淋明油/撒葱]
   【原理】勾芡出锅前淋入防结块；葱花最后放保留挥发香气
6. 出锅装盘

【预期成品】
- 质地：[外层微焦/脆嫩/软滑——按主料填写]
- 色泽：[美拉德褐/翠绿/酱色]
- 风味：[鲜/香/辣/锅气]
- 营养保留率：维生素 C 70–80%，蛋白质 90%+

【安全边界】
- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层 < 260°C

【成功关键】
- [2-3 条，从上面步骤推导]

【常见错误】
- 错误1：原因和解决方法
- 错误2：原因和解决方法
```

### 2. 蒸制模板（100°C，水蒸气，分钟~小时级）

**适用**：鱼、蛋羹、贝类、粉蒸肉、蔬菜、面点（馒头包子）；营养保留要求高的食材
**不适用**：追求焦香/脆皮/褐变的菜

```
【菜品名】

【食材】
主料：[食材+用量]
腌料/铺底：[姜丝/葱段/铺底蔬菜]
调味料：[蒸鱼豉油/生抽/盐/香油]

【因子分析】
- 食材因子：蛋白质变性温度（鱼 40–60°C 凝固）、厚度决定中心熟透时间
- 烹饪方式因子：蒸（100°C 水蒸气，温和传导），无焦化反应，营养保留最高（90%+）
- 调味因子：盐腌过早导致肉质变紧（渗透压脱水）；豉油/生抽出锅后淋（不参与蒸制）

【步骤】
1. 预处理：[去腥处理 + 划花刀]
   【原理】盐搓/料酒姜腌去腥；花刀缩短热传导距离
2. 水开上锅：[大火蒸 X 分钟（按厚度）]
   【原理】水开后再上锅，蒸汽持续 100°C；中途不开盖防温度骤降
3. 蒸制时间判定：[鱼 8–10 分钟/蛋 12–15 分钟/粉蒸肉 40–60 分钟]
   【原理】中心温度达 70°C+ 即熟（蛋白质完全变性）；过蒸则肉柴蛋老
4. 出锅调味：[淋豉油/香油，撒葱丝，可热油泼香]
   【原理】增鲜剂/葱花出锅前放保留风味；热油激发香气（美拉德/挥发油）
5. 装盘

【预期成品】
- 质地：嫩滑（蛋白未过度变性）
- 色泽：食材本色 + 豉油色
- 风味：原味鲜甜
- 营养保留率：90%+（水溶性维生素几乎不流失）

【安全边界】
- 必须蒸熟（中心 >70°C）：鱼类寄生虫/细菌杀灭
- 蛋类避免过蒸（蜂窝状 = 变性过度）
- 蒸锅水要足，防干烧

【成功关键】
- [2-3 条]

【常见错误】
- 错误1：原因和解决方法
- 错误2：原因和解决方法
```

### 3. 炖煮模板（85–95°C，液体传导，小时级）

**适用**：大块肉、带骨肉、牛腩/猪蹄（高结缔组织）、老火汤、卤味、咖喱、粥
**不适用**：追求脆嫩口感的食材

```
【菜品名】- XX版

【食材】
主料：[肉类/骨头/根茎+用量]
配料：[蔬菜/豆制品/菌菇]
调味料：[生抽/老抽/糖/香料包]
辅料：[姜片/料酒/葱结]

【因子分析】
- 食材因子：胶原蛋白含量（决定浓稠度和软烂度）；结缔组织需长时间水解
- 烹饪方式因子：炖煮（85–95°C 微沸，小时级），激活胶原蛋白水解（→明胶）+ 风味物质溶出；>100°C 剧烈沸腾则肉柴
- 调味因子：盐最后 15 分钟（渗透压抑制风味扩散）；香料油煸后加入（挥发油脂溶性）；老抽中途加（焦糖色均匀扩散）

【步骤】
1. 焯水：[冷水下锅煮开撇沫]
   【原理】冷水升温使血蛋白缓慢析出，浮沫上浮
2. 煸香：[姜片/香料用油煸出香味]
   【原理】五香粉/十三香油爆提取脂溶性风味（加水前煸）
3. 上色（红烧类）：[炒糖色 或 老抽+糖]
   【原理】焦糖化反应（160–180°C）产生红亮色泽
4. 炖煮：[加热水没过食材，大火烧开转小火 X 小时]
   【原理】85–95°C 微沸：胶原蛋白水解为明胶；中途不加冷水（温度骤降中止水解）
5. 调味收尾：[最后 15 分钟加盐，大火收汁]
   【原理】盐晚放避免渗透压抑制风味扩散；收汁浓缩风味（水分蒸发）
6. 出锅

【预期成品】
- 质地：软烂脱骨（胶原蛋白 → 明胶）
- 色泽：红亮/乳白（红烧焦糖色 / 脂肪乳化）
- 风味：醇厚鲜香
- 营养保留率：蛋白质溶出率 40–60%（取决于炖煮时间）

【安全边界】
- 保持微沸，避免剧烈沸腾（肉变柴）
- 炖煮 < 4 小时（嘌呤随时间累积）
- 高压锅可缩短时间（115°C，时间减半）

### 5. 油炸模板（170–190°C，深度油炸，分钟级）

**适用**：裹粉肉类（炸鸡/炸猪排）、天妇罗、薯条；需要整体酥脆外壳的食材

- 调味因子：腌料入味后炸（调味渗透）；撒粉调味料出锅后撒（热敏感：花椒粉/孜然粉久热麻味消失）

1. 预处理：[腌制入味 + 裹粉（拍粉→拖蛋液→裹面包糠）]

4. 沥油：[捞出控油/吸油纸]

5. 调味：[出锅后立即撒椒盐/孜然等]

- 用油反复使用 < 3 次（氧化产物累积）

```
【青椒炒肉丝 - 家常版】（炒制模板）

【食材】
主料：猪里脊肉200g、青椒2个
腌料：料酒1汤匙、生抽1茶匙、淀粉1茶匙、蛋清半个
调味料：生抽1汤匙、老抽1茶匙、盐1/2茶匙、糖1/4茶匙
辅料：蒜片3瓣、食用油3汤匙

【因子分析】
- 食材因子：猪里脊蛋白质约20%、脂肪低、肌纤维细（嫩）；青椒水分>90%、维生素C高（热敏）、细胞壁薄
- 烹饪方式因子：炒（200–300°C，2分钟级），激活美拉德反应 + 表面蛋白快速变性锁水
- 调味因子：生抽沿锅边淋入（140°C+美拉德锅气）；盐出锅前（减少渗透压失水）；老抽中途（焦糖色扩散）

【步骤】
1. 切肉丝：猪里脊逆纹切丝，加腌料抓匀腌15分钟
   【原理】逆纹切切断肌纤维口感嫩；淀粉蛋清包裹锁水
2. 切青椒：去籽切丝（与肉丝粗细一致）
   【原理】大小一致受热均匀
3. 炒肉丝：热锅冷油，油热放肉丝快速划散，变色盛出
   【原理】大火快炒锁住水分，变色即熟不会老
4. 炒青椒：补油，先下蒜片爆香，加青椒丝大火翻炒1分钟
   【原理】蒜150–180°C易褐变，金黄即出；青椒短时保脆
5. 合炒调味：倒回肉丝，沿锅边淋生抽激发锅气，加老抽上色，加盐，翻炒均匀
   【原理】参考 [[调味料下锅时机]]：生抽沿锅边高温激发美拉德；盐缩短接触时间

## 健康烹饪建议

### 减油技巧
```
1. 使用不粘锅，减少用油量
2. 先焯水再炒，缩短炒制时间
3. 用喷油壶，均匀喷洒
4. 蒸、煮、凉拌代替炒、煎、炸
```

### 减盐技巧
```
1. 使用天然调味料（葱姜蒜、香料）
2. 酱油、豆瓣酱等含盐调味料减少用量
3. 出锅前放盐，减少用盐量
4. 使用低钠盐
```

### 保留营养技巧
```
1. 蔬菜先洗后切，减少水溶性维生素流失
2. 大火快炒，缩短加热时间
3. 蒸比煮更能保留营养
4. 肉汤一起喝，回收流失的营养
```

### 食品安全提示
```
1. 生熟分开，避免交叉污染
2. 肉类要彻底煮熟
3. 冰箱不是保险箱，注意保质期
4. 剩菜彻底加热再食用
```
