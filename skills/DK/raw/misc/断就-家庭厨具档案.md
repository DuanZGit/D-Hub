# 断就 - 家庭厨具档案

> 用途：DK 推荐菜谱时匹配实际可用厨具，避免推荐做不了的菜。
> 最后更新：2026-09-26

---

## 当前厨具清单

| # | 厨具 | 特点 | 擅长 | 不擅长 |
|---|------|------|------|--------|
| 1 | **雪平锅** | 日式单柄铝锅，带锤纹，导热快、轻便 | 煮面/煮馄饨/焯水/煮汤/煮粥/热牛奶 | 不适合煎炒（浅、易糊） |
| 2 | **不粘平底锅** | 涂层不粘 | 煎蛋/煎鱼/炒蛋/少油炒菜 | 不能空烧、不能用金属铲、怕高温（<260°C）、**出不了牛排焦壳** |
| 3 | **熟铁圆底锅** | 升温极快，薄壁，**圆底**，有锅气 | 爆炒/炒青菜/颠勺/需要大火快出的菜 | **不适合煎牛排**（圆底油往中间聚、牛排滑到锅边、接触面小受热不均）；需锅架/灶圈支撑；不能久煮酸性食物 |
| 4 | **微蒸烤箱** | 微波+蒸汽+烤 三合一 | 蒸蛋/蒸鱼/复热/烤鸡翅/烤蔬菜/解冻 | 容量有限，不适合大份炖菜 |
| 5 | **宜家森舒尔 SENSUELL 24cm 平底锅**（2026-09-26 新增） | **不锈钢 + 铝芯夹层**，无涂层，平底，可用金属铲 | **煎牛排主力**（耐高温、出焦壳、锅底焦化物可 deglaze 做酱）；煎鱼/煎鸡排；需要收酱汁的西式菜；炒 | **无涂层会粘**（必须预热 + 油膜 + 食材干燥三件套）；**热容（热惯性）低于铸铁**——铸铁锅体厚、体积热容大，下肉后温度掉得少；不锈钢锅靠铝芯夹层做到**导热均匀**（注：铝的导热 237 W/m·K，远高于铸铁 ~50 和不锈钢本体 ~16，所以夹层锅的均热是**优于**铸铁的，弱项是热惯性不是导热）；不能用钢丝球猛刷 |

## 今晚菜单厨具匹配（2026-09-26 · 3 人）

**M5-M6 眼肉牛排 + 黑松露奶油口蘑 + 农家小炒肉 + 咸蛋黄土豆丝 + 水煮西兰花 + 手撕包菜**

| 菜 | 用什么锅 | 理由 |
|----|---------|------|
| 煎牛排（1.4cm 眼肉） | **不锈钢 24cm** | 平底 + 耐高温 200-210°C；**不锈钢锅的额外红利**：煎完的锅底焦化物用淡奶油去釉，直接变成牛排酱或倒进口蘑酱 |
| 黑松露奶油口蘑 | **不锈钢 24cm**（接牛排的锅） | 锅体干燥、有余温，直接续做；**用牛排锅底的 fond 提味** |
| 农家小炒肉 | **熟铁圆底锅** | 需要大火爆炒出锅气；五花肉煸油 + 青椒虎皮靠升温快 |
| 咸蛋黄土豆丝 | **熟铁圆底锅**（或不粘锅） | 先小火炒金沙再转大火裹丝；圆底锅火候响应快 |
| 水煮西兰花（牛排配菜） | **雪平锅** | 焯水专用，导热快 |
| 手撕包菜 | **熟铁圆底锅** | 大火快炒，出锅气 |
| 蒸咸鸭蛋 | **微蒸烤箱** | 蒸 10 分钟，蛋黄更沙好剥 |
| 煮米饭 | 电饭煲 | — |

> ⚠️ **熟铁圆底锅是今晚的瓶颈**：小炒肉、土豆丝、手撕包菜三道都要它，且都是「出锅即吃」的快炒 → 动线上必须串行排开（见合集时间线）。

## 不锈钢锅使用要点（新锅，第一次用前读一遍）

| 事项 | 做法 | 原理 |
|------|------|------|
| **预热** | 中火空烧 2-3 分钟再下油 | **两个真机理**：① 高温下食物蛋白质会与金属表面**形成化学键**才粘（下锅前把锅烧透，食材表面瞬间脱水变性成焦壳，在粘附发生前就隔开了）② 油受热渗入金属微观孔隙，形成物理隔离膜。与「均热慢」无关——夹层锅的均热其实是好的 |
| **判温** | 洒几滴水，**水珠在锅面滚动**而不立刻蒸发 = 约 190-200°C，正好 | 莱顿弗罗斯特效应，比铸铁的"看烟"更准 |
| **油膜** | 薄薄一层高烟点油（花生/米糠/葡萄籽），晃匀 | 无涂层锅的防粘全靠这层油膜 |
| **食材干燥** | 下锅前用厨房纸把表面吸到发涩 | 水分是粘锅和"变煮"的共同元凶 |
| **别急着动** | 下锅后 60 秒内不要翻；焦壳成型会自然脱膜 | 粘住 = 时间还不够，再等 20 秒，别硬铲 |
| **分开煎** | 2 块牛排一块一块煎 | 几何就算不下：250g 眼肉 / 密度约 1.05 g/cm³ → 体积 ≈ 238 cm³，除 1.4cm 厚 ≈ **170 cm²/块**（约 13×13cm）。24cm 锅内径约 20-22cm → 可用底面积约 314-380 cm²，**两块共 340 cm² 几乎占满**，还会挤到锅壁弧形区。挤在一起 = 中间出不了焦壳 + 锅温被两块冷肉同时拉低 `[经验：按尺寸推算，未实测]`（本档旧版写「一次两块把锅温拉到 150°C 以下」为估计值） |
| **去釉（deglaze）** | 煎完关火，倒淡奶油/水，用木铲刮起锅底焦化物 | **不锈钢锅独有红利**，焦化物是浓缩肉香 |
| **清洗** | 温水泡软 → 软刷；**不用钢丝球猛刷** | 免刮花，也免破坏表面钝化层 |
| **不要** | 不要长时间空烧到发蓝、不要骤冷冲水 | 夹层变形会导致锅底不平 |

## 缺口提醒

| 缺什么 | 影响 |
|--------|------|
| 炖锅/砂锅 | 做不了土豆炖小黄鱼、排骨汤等需要长时间炖的菜 |
| 空气炸锅 | 无（可选，微蒸烤箱可部分替代） |
| 大汤锅 | 煮馄饨/面用雪平锅够，但多人份火锅不够 |
| ~~平底铸铁锅~~ | **已由不锈钢 24cm 覆盖煎牛排需求**；若追求极致焦壳仍可考虑铸铁，但非必需 |
