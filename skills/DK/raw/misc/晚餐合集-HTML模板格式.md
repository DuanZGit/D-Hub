# 晚餐合集 HTML 模板格式（v1）

## 文件命名
`YYYY-MM-DD-晚餐合集.html`

## 输出路径
`/var/minis/workspace/`

## 链接格式
`minis://workspace/2026-08-03-晚餐合集.html`

## Section 结构（12 个，固定顺序）

### 1. 🍽️ 今日菜单
- 3 个 menu-card（按菜分：荤 / 素 / 汤 或其他组合）
- 每张卡片含：role / name / desc / "查看详细菜谱 →" 跳转链接

### 2. 📋 快速信息
- 8 个 quick-info-grid 项：日期 / 餐次 / 菜数 / 总时长 / 份量 / 难度 / 风格 / 主导菜

### 3. 🛒 食材汇总（去重）
- 4 列表格：食材 / 用量 / 用途 / 菜品（带 dish-tag）
- 重点：去重（食用油/葱/姜等共用料合并计算）

### 4. ⏱️ 厨房动线
- timeline 组件，按时间顺序排每个步骤
- 含 T+X 时间标记 + 菜品 + 动作描述

### 5. 💡 因子分析
- 每菜 1 个 factor-block（食材因子 + 烹饪方式因子 + 调味因子）

### 6. ⚗️ 反应激活
- 4 列表格：菜品 / 核心反应 / 条件 / 效果

### 7. 🎯 预期成品
- 4 列表格：菜品 / 质地 / 色泽 / 风味 / 营养保留

### 8. ⚠️ 安全边界
- 多条 callout，每条 1 个具体边界条件
- 用 warn 标识关键风险
- **必含**：含液体调料的菜（醋/料酒/酱油）必须加防溅油警告（参考 wiki/techniques/防溅油.md）
- 2026-08-03 案例：醋溜豆芽必须显示防溅油 callout

### 9. ❌ 缺口提醒
- gap-list 列出原计划但缺失的原料

### 10. ✅ 成功关键 + ❌ 常见错误
- 每菜一组"✅ 关键" + "❌ 错误" 配对

### 11. 🔗 相关卡片
- 各菜详细因子卡的跳转链接
- 关联因子页面的跳转链接（美拉德反应、蛋白质变性等）

### 12. ✅ 置信度
- 1 条 success callout，含置信级别 + 依据 + 边界

## 配色
- primary: #c4452c（红，DK 食材主色）
- accent: #5a7d3a（绿，用于 h3 / factor-block）
- warn: #d4a017（黄，用于警告 callout）
- light: #fbeeea（背景）
- 沿用现有 wiki-to-html-v2.py 模板的字体和卡片样式
