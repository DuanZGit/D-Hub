# 洋葱口蘑鸡蛋

## 来源
DK 因子模型生成（基于食品化学原理 + 中式烹饪经验）

## 来源网址
https://github.com/Anduin2017/HowToCook（参考类似做法）

## 基本信息
- 菜品类型：家常菜
- 烹饪方式：炒
- 难度：简单
- 时间：8-15 分钟（依主料而异）
- 份量：2-3 人份
- 风味：鲜香 + 微甜（洋葱焦糖化）
- 采集时间：2026-08-02

## 食材
- 主料：鸡蛋 3 个 + 洋葱 1 个 + 口蘑 150g

## 调料（按使用顺序）
- 盐 1/2 茶匙
- 生抽 1 汤匙
- 料酒 1 茶匙
- 葱花 适量
- 食用油 3 汤匙

## 步骤
1. **打蛋**：鸡蛋打散加 1/4 茶匙盐
2. **炒蛋**：热锅冷油 170°C 倒入蛋液，凝固即出
3. **炒菇**：余油下口蘑片炒至出汁变软
4. **炒洋葱**：下洋葱翻炒至半透明
5. **合炒**：倒回鸡蛋，加生抽调味翻匀 30 秒
6. **出锅**：撒葱花装盘

## 核心原理（因子分析）

- **食材因子**：洋葱（含硫化合物/催泪因子 syn-propanethial-S-oxide）+ 口蘑（鲜味氨基酸/谷氨酸）+ 鸡蛋（蛋白质/美拉德）
- **烹饪方式因子**：炒制：蛋液先炒定型，配菜后下吸收蛋香
- **调味因子**（参考 [[调味料下锅时机]]）：
  - 盐缩短接触时间（减少渗透压失水）
  - 生抽沿锅边淋入（140°C+ 美拉德锅气）
  - 醋分两次（第一次高温挥发留香/第二次出锅前留酸）
  - 增鲜剂（蚝油/味精）出锅前放（>120°C 降解）
  - 姜蒜葱爆锅：冷油先下姜 → 姜出香后下蒜 → 出锅前撒葱

## 反应激活
- 美拉德 + 焦糖化：洋葱 160°C+ 硫化合物分解 + 糖焦化（甜味+褐变）
- 鲜味协同：口蘑谷氨酸 + 鸡蛋核苷酸 = 鲜味叠加
- 蛋白质变性：鸡蛋 160-180°C 凝固锁水
- 渗透压：盐最后放（蘑菇保水）

## 预期成品
- **质地**：按主料判断（火候到位时脆嫩/嫩滑/微焦）
- **色泽**：食材本色 + 调味料调色
- **风味**：鲜香 + 微甜（洋葱焦糖化）
- **营养保留率**：维生素 C 70-80%（短时高温），蛋白质 90%+

## 安全边界
- 蛋炒至凝固即可；洋葱炒至半透明（保留脆感）；口蘑炒出汁
- 油温 < 烟点（>180°C 产生有害 PM2.5）

## 成功关键
- 炒制：蛋液先炒定型，配菜后下吸收蛋香
- 调味料按 [[调味料下锅时机]] 时序加入
- 火候是关键：大火快炒，温度足、时间短

## 常见错误
- 火太小 → 出水/老柴 → 大火快炒
- 盐放太早 → 食材出水 → 盐分两次/最后
- 翻炒太久 → 过熟失脆 → 按主料计时
- 增鲜剂过早 → 鲜味降解 → 出锅前放
