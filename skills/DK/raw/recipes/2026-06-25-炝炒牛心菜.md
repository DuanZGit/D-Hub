# 炝炒牛心菜

## 基本信息
- **难度**：简单
- **时间**：10分钟
- **份量**：2人份
- **口味**：香辣清脆
- **来源**：香哈网 https://www.xiangha.com/caipu/100701211.html

## 用料
| 食材 | 用量 |
|------|------|
| 牛心菜 | 半个（约300g） |
| 花椒 | 1小勺 |
| 红干辣椒 | 3-5个 |
| 食用油 | 2汤匙 |
| 味极鲜（生抽） | 1大勺 |
| 盐 | 适量 |
| 鸡精 | 少许 |

## 制作步骤
1. 牛心菜手撕成小块，洗净沥干
2. 热锅倒油，放入花椒小火炸香
3. 加入红干辣椒段爆香
4. 转大火，倒入牛心菜快速翻炒
5. 炒至菜叶变软但仍保持脆度（约2分钟）
6. 加入味极鲜、盐、鸡精调味
7. 快速翻匀即可出锅

## 关键技巧
- **大火快炒**：保持牛心菜脆爽口感
- **花椒+干辣椒**：炝炒的灵魂，先炸出香味
- **手撕比刀切**：断面不规则更易入味
