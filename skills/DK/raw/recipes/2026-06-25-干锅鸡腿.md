# 干锅鸡腿

## 基本信息
- **难度**：普通
- **时间**：30分钟
- **份量**：2人份
- **口味**：咸鲜微辣
- **来源**：香哈网 https://www.xiangha.com/caipu/88808310.html

## 食材用料
| 食材 | 用量 |
|------|------|
| 鸡腿 | 1-2个 |
| 绿豆芽 | 适量 |
| 小红辣椒 | 少许 |
| 大料（八角） | 1个 |
| 料酒 | 少许 |
| 蚝油 | 适量 |
| 盐 | 少许 |
| 糖 | 少许 |
| 白胡椒粉 | 少许 |
| 食用油 | 适量 |
| 葱姜 | 各少许 |
| 白醋 | 少许 |

## 制作步骤
1. 鸡腿洗净剁块，葱姜蒜、大料、调味料备齐
2. 绿豆芽洗净焯水一分钟，放入砂锅底部备用
3. 鸡块控净水分，葱姜蒜红辣椒切片
4. 碗汁兑好：蚝油、白醋、糖、盐、白胡椒粉混合
5. 热锅凉油爆香大料、葱姜蒜片
6. 倒入鸡块中火炒至断生
7. 倒入调好的碗汁，中火炖一会儿入味
8. 汤汁变少时加入红辣椒，改大火炒匀收汁
9. 倒入砂锅中的绿豆芽上，小火焖炒一会
10. 让汤汁渗入豆芽中，关火即可

## 小贴士
- 鸡腿要选新鲜的
- 喜欢辣味可适当添加红辣椒
- 碗汁提前兑好更方便

## 健康功效
- 鸡腿：温中补虚
- 绿豆芽：活血化瘀
- 料酒：活血化瘀
