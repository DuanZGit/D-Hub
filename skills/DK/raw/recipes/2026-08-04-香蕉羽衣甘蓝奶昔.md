# 香蕉羽衣甘蓝奶昔

## 来源
DK 因子模型生成（基于食品化学原理 + 蔬果奶昔通用做法）

## 来源网址
（无外部来源，基于因子模型）

## 基本信息
- 菜品类型：饮品 / 奶昔
- 烹饪方式：搅拌（无加热）
- 难度：★（1/5，最简单）
- 时间：5 分钟
- 份量：1-2 人份（约 350ml）
- 风味：香蕉甜 + 奶香 + 羽衣甘蓝清香
- 采集时间：2026-08-04

## 食材
- 香蕉 1 根（熟透更甜）
- 羽衣甘蓝 1 小把（约 30-50g，去梗）
- 牛奶 200-250ml（冷或常温）
- 蜂蜜 1 茶匙（可选，香蕉不够甜时加）

## 步骤
1. **准备食材**：香蕉剥皮切段（方便搅拌）；羽衣甘蓝洗净，**去梗**（梗纤维粗，搅不碎）
2. **软化选择**：
   - 香蕉冷冻过/冰过 → 奶昔更冰沙口感
   - 香蕉常温 → 奶昔更滑顺
3. **放入搅拌机**：先放液体（牛奶）→ 再放软食材（香蕉）→ 最后放硬食材（羽衣甘蓝）
4. **搅拌**：高速 30-60 秒，至完全细腻无颗粒
5. **调味**：尝一下，不够甜加蜂蜜，再搅 10 秒
6. **装杯**：倒入杯中，趁新鲜喝（维 C 接触空气易氧化）

## 核心原理（因子模型）

### 食材因子
- **香蕉**：果糖含量高（成熟后 15%+），淀粉→糖转化完成后甜度最佳
- **羽衣甘蓝**：纤维粗硬，**必须去梗**（梗纤维粗 3-5 倍，搅不碎）
- **牛奶**：酪蛋白乳化脂肪，提供顺滑口感 + 钙质

### 物理因子
- **搅拌顺序**：液体 → 软 → 硬（避免刀片空转，刀片先打到液体再带动固体）
- **搅拌时长**：30-60 秒足够（太长 = 摩擦升温，颜色变暗）
- **维 C 氧化**：搅拌时接触空气中的氧，维 C 含量会下降 30%+（5 分钟内）

### 调味因子
- **香蕉选熟透**：表皮有黑斑 = 甜度最高、淀粉已转化
- **蜂蜜按需**：熟透香蕉 + 牛奶已有甜度，蜂蜜可省
- **不加糖也行**：健康人群靠香蕉天然甜度

## 营养配比（每份约 350ml）

| 营养素 | 含量 | 备注 |
|--------|------|------|
| 热量 | 180-220 kcal | 主要来自香蕉 + 牛奶 |
| 蛋白质 | 6-8g | 牛奶提供 |
| 脂肪 | 4-6g | 牛奶 + 香蕉 |
| 碳水 | 30-35g | 香蕉果糖 |
| 膳食纤维 | 3-4g | 羽衣甘蓝 + 香蕉 |
| 钙 | 200mg | 牛奶 |
| 维 C | 30-50mg | 羽衣甘蓝（搅拌后损失一部分） |
| 钾 | 500mg | 香蕉 |

### 营养特点
- **维 C + 钙** 组合（羽衣甘蓝 + 牛奶）
- **钾** 含量高（香蕉）→ 适合运动后补电解质
- **膳食纤维** 充足（羽衣甘蓝）→ 饱腹感强
- **消化负担小**：搅拌破壁后纤维变短，肠胃弱者友好

## 预期成品
- **质地**：细腻顺滑（无颗粒感）
- **色泽**：浅绿色（羽衣甘蓝）+ 淡黄色（香蕉）
- **风味**：香蕉甜主导 + 奶香 + 羽衣甘蓝清香
- **营养保留率**：维 C 70%（搅拌接触空气 30% 损失）

## 安全边界
- ⚠️ 羽衣甘蓝**必须去梗**（梗纤维粗，搅不碎，会卡喉咙）
- ⚠️ 香蕉选熟透（生香蕉淀粉高，不甜）
- ⚠️ 搅拌时间 ≤ 2 分钟（太久升温破坏维 C）
- ⚠️ 现做现喝（放置 30 分钟维 C 损失 50%）

## 成功关键
- ✅ **羽衣甘蓝去梗**（关键中的关键）
- ✅ **搅拌顺序**：液体 → 软 → 硬
- ✅ **香蕉选熟透**（黑斑最好）
- ✅ **现做现喝**（维 C 易氧化）

## 常见错误
- ❌ 不去梗 → 搅不碎，渣渣多
- ❌ 香蕉生 → 不甜，淀粉多
- ❌ 搅拌太久 → 发热 + 颜色变暗
- ❌ 放太久再喝 → 维 C 流失 + 氧化变褐
- ❌ 牛奶太少 → 太稠像粥；太多 → 味淡

## 比例调节（按口味）

| 想要 | 调整 |
|------|------|

| 更奶香 | 牛奶 +50ml |
