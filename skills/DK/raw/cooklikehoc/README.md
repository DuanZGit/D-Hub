## ⚠️ 使用前必读：这不是家庭食谱

1. **批量口径**：配料与步骤是**中央厨房/门店出品**口径，主料动辄 500–2000g，油按 100g 级投放（例：宫保鸡丁一次投 180g 大豆油、1050g 鸡丁）。
2. **依赖工业半成品**：相当比例菜品依赖老乡鸡中央厨房自产预制料（`配料/` 目录 40 项，官方**未公布配比**）或供应商专供半成品（圣农/正大/凤祥/圣恩等），**家庭无对应商品**，只能近似复刻。
3. **工艺参数不完整**：多数条目只给了油温/时间，未给火候曲线、勾芡、腌制时长等细节。
