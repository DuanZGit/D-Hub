## 调味料下锅时机总表

| 调味/食材 | 下锅时机 | 原理/作用 |
|-----------|---------|----------|
| 盐（炒肉） | 肉变色、表面蛋白质凝固后 | 避免渗透压提前抽走水分，肉不会变柴 |
| 盐（炒青菜） | 出锅前几秒 | 青菜细胞壁薄，放早了会大量出水变煮菜 |
| 盐（煲汤） | 最后15分钟 | 太早放蛋白质提前凝固，鲜味出不来 |
| 生抽 | 油热后沿锅边淋入 | 高温激发酱香，是"锅气"的重要来源 |
| 老抽 | 中途加入 | 主要管上色，太早发黑，太晚上色来不及 |
| 蚝油/味精/鸡精 | 出锅前，余温翻匀 | 超过120°C鲜味流失甚至发苦 |
| 姜 | 冷油时先下 | 最耐热，需要慢慢煸出香味 |
| 蒜 | 姜出香后再下 | 容易糊，微微金黄就下主菜 |
| 葱 | 快出锅时最后放 | 最娇气，翻几下就出锅保留葱香 |
| 醋（第一次） | 热油时沿锅边烹入 | 高温烧掉酸味，只留浓郁香气 |
| 醋（第二次） | 出锅前点几滴 | 保留酸爽，糖醋排骨缺这步就没灵魂 |
| 白胡椒粉 | 出锅前放 | 久煮会发苦 |
| 花椒粉 | 出锅前放 | 高温煮几分钟麻味跑光只剩苦 |
| 五香粉/十三香 | 加水前用油煸一下 | 不煸的话香味出不来 |
| 孜然粉 | 肉快熟时撒 | 再烤2分钟香味拉满 |
| 水淀粉（勾芡） | 出锅前淋入，边淋边搅 | 提前放会沉底结块变浆糊 |

## 前置技巧：热锅冷油

锅烧到冒烟再倒油，锅底温度超过200°C，食材下锅时形成蒸汽膜，不粘不糊，同时表面快速焦化锁住水分，是家庭灶台逼近饭店效果的第一步。
