# 面包

## 快速信息
- 分类：食谱
- 难度：中等
- 时间：180 分钟（含发酵）
- 份量：1 个 loaf
- 关键词：烘焙、酵母、蓬松、香气

## 因子分析

- **烹饪方式因子**：烘烤（150–250°C，热辐射+对流，分钟~小时级）：整体均匀升温 + 表面美拉德/焦糖化形成焦壳
- **食材因子**：高筋面粉（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **反应条件**：关键温度 28-35°C、180-220°C（反应激活阈值）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
面包是西式主食，通过酵母发酵产生 CO₂，使面团膨胀松软，高温烘焙形成焦香 crust。

**发酵原理**：
- 酵母分解糖分产生 CO₂，面团膨胀
- 适宜温度 28-35°C，湿度 75%
- 发酵不足：组织紧密；发酵过度：酸味重

**烘焙原理**：
- 烤箱 180-220°C，面饼快速膨胀
- 表面美拉德反应，形成焦香 crust
- 内部淀粉糊化、蛋白质变性

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 高筋面粉 | 300g | 面筋网络 |
| 酵母 | 4g | 发酵 |
| 糖 | 20g | 发酵底物 |
| 盐 | 5g | 增强筋度 |
| 黄油 | 30g | 柔软、香气 |
| 牛奶 | 180ml | 液体 |

## 制作步骤
1. **和面**：面粉+酵母+糖+盐+牛奶，揉成面团，加黄油揉至扩展阶段。
2. **一次发酵**：盖盖发酵 1 小时至两倍大。
3. **排气整形**：揉匀排气，整形成 loaf 或 round。
4. **二次发酵**：放烤盘，发酵 30-40 分钟至两倍大。
5. **烘焙**：烤箱 180-200°C，烤 30-35 分钟。
6. **冷却**：取出后网架上冷却。

## 关键技巧
- **酵母水温**：35°C 左右，过热杀死酵母
- **揉面到位**：揉至扩展阶段，能拉出薄膜
- **二次发酵**：决定成品松软度
- **烤箱预热**：温度不足影响膨胀

## 预期成品

- **质地**：外脆内嫩（焦壳 + 内部多汁）
- **色泽**：金黄 / 焦糖色
- **风味**：焦香 + 香料渗透味
- **营养保留率**：蛋白质 85–90%

## 安全边界

- 肉类中心温度：禽 74°C+ / 猪 71°C+ / 牛 63°C+
- 锡纸包裹减少表面过度焦化
- 烤箱内禁用普通玻璃容器
- 关键反应温度：28-35°C、180-220°C，避免超温产生有害副产物
- 操作注意：
  - 面包为什么不发？ → 酵母失效、水温过高/过低、发酵时间不足。检查酵母活性。
  - 面包内部太密？ → 揉面不足、发酵不足、或烤箱温度太低。充分揉面，保证发酵。

## 常见问题
**Q: 面包为什么不发？**
A: 酵母失效、水温过高/过低、发酵时间不足。检查酵母活性。

**Q: 面包内部太密？**
A: 揉面不足、发酵不足、或烤箱温度太低。充分揉面，保证发酵。

**Q: 面包表面太硬？**
A: 温度过高、或烘焙时间太长。控制温度和时间。
