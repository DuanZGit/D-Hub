# 干锅鸡腿

## 快速信息
- 分类：食谱
- 难度：普通
- 时间：30分钟
- 份量：2人份
- 口味：咸鲜微辣

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：鸡腿（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
干锅鸡腿通过先炒后焖的方式，使鸡腿肉入味且保持嫩滑。美拉德反应在炒制过程中产生焦香风味，碗汁中的蚝油和糖形成复合鲜甜口感。

## 制作步骤

### 阶段一：准备
1. **鸡腿处理**：鸡腿洗净剁块，控干水分
   - 【原理】控干水分避免炒制时溅油

2. **绿豆芽处理**：洗净焯水一分钟，放入砂锅底部备用
   - 【原理】焯水去除豆腥味，垫底吸收汤汁

3. **碗汁调制**：蚝油、白醋、糖、盐、白胡椒粉混合
   - 【原理】提前兑好碗汁，避免炒制过程中手忙脚乱

### 阶段二：炒制
4. **爆香**：热锅凉油爆香大料、葱姜蒜片
   - 【原理】低温油释放香料香味物质

5. **炒鸡块**：倒入鸡块中火炒至断生
   - 【原理】中火使鸡肉均匀受热，避免外焦内生

6. **入味**：倒入调好的碗汁，中火炖一会儿入味
   - 【原理】汤汁沸腾使调味料渗透进鸡肉

7. **收汁**：汤汁变少时加入红辣椒，改大火炒匀收汁
   - 【原理】大火加速水分蒸发，浓缩味道

8. **组装**：倒入砂锅中的绿豆芽上，小火焖炒一会
   - 【原理】让汤汁渗入豆芽中，增加层次感

9. **出锅**：关火即可

## 营养信息（每份）
- 热量：约 350-450 千卡（取决于用油量）
- 蛋白质：约 25g（鸡腿提供）
- 脂肪：约 20-30g
- 碳水化合物：约 10g

## 健康功效
- **鸡腿**：温中补虚，提供优质蛋白和铁
- **绿豆芽**：活血化瘀，富含维生素C
- **料酒**：活血化瘀，去腥增香

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 鸡腿怎么炒不散？ → 1）鸡腿块不要切太小；2）炒制时不要频繁翻动，一面定型后再翻；3）先用大火锁住表面水分。
  - 没有砂锅怎么办？ → 可以用深底炒锅代替，最后转入保温的小锅或石锅中上桌。

## 常见问题

**Q: 鸡腿怎么炒不散？**
A: 1）鸡腿块不要切太小；2）炒制时不要频繁翻动，一面定型后再翻；3）先用大火锁住表面水分。

**Q: 没有砂锅怎么办？**
A: 可以用深底炒锅代替，最后转入保温的小锅或石锅中上桌。

**Q: 喜欢更辣怎么办？**
A: 可添加干辣椒段、花椒、辣椒粉，或最后淋上辣油。
