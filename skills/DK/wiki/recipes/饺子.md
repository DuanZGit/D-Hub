# 饺子

## 快速信息
- 分类：食谱
- 难度：中等
- 时间：60 分钟（含和面）
- 份量：30-40 个

## 因子分析

- **烹饪方式因子**：蒸（100°C，水蒸气传导，分钟~小时级）：无焦化反应，温和均匀升温，营养保留最高（90%+）
- **食材因子**：中筋面粉（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
饺子是面皮包裹馅料，通过**煮制**或**蒸制**使面皮熟透、馅料加热的传统美食。

**面皮原理**：
- 面粉+水揉成面团，形成面筋网络
- 擀皮后薄而韧，煮熟后透明柔软
- 面筋蛋白变性凝固，保持形状

**馅料原理**：
- 肉类蛋白质变性，产生肉香
- 蔬菜出水，与肉馅混合
- 调味料渗透，味道融合

## 制作步骤
1. **和面**：面粉加冷水，揉成光滑面团，醒面 30 分钟。
2. **调馅**：肉馅加葱姜末、生抽、盐、香油，顺时针搅打；蔬菜切碎挤干水分，与肉馅混合。
3. **擀皮**：面团分成小剂子，擀成中间厚边缘薄的圆片。
4. **包制**：放入馅料，对折捏紧边缘。
5. **煮制**：水沸后下饺子，点 3 次冷水，再次沸腾捞出。
6. **蘸料**：醋、蒜泥、辣椒油等。

## 关键技巧
- **醒面**：面团充分醒面，面筋松弛，更好擀制
- **蔬菜挤水**：避免馅料出水，饺子易破
- **点水煮**：水沸后加冷水，控制温度，避免煮破
- **捏紧边缘**：防止煮时开口

## 预期成品

- **质地**：嫩滑（蛋白未过度变性）
- **色泽**：食材本色
- **风味**：原味鲜甜
- **营养保留率**：90%+（水溶性维生素几乎不流失）

## 安全边界

- 必须蒸熟（中心温度 >70°C），杀灭寄生虫/细菌
- 蛋类避免过蒸（蜂窝状 = 蛋白变性过度）
- 蒸锅水要足，防干烧
- 操作注意：
  - 饺子皮容易破？ → 面皮太薄、馅料太多、或煮时水太少。控制皮厚 1mm 左右，馅料适量，水要宽。
  - 如何让馅料更多汁？ → 肉馅中加少量水或高汤，顺时针搅打至吸收；或加皮冻。

## 常见问题
**Q: 饺子皮容易破？**
A: 面皮太薄、馅料太多、或煮时水太少。控制皮厚 1mm 左右，馅料适量，水要宽。

**Q: 如何让馅料更多汁？**
A: 肉馅中加少量水或高汤，顺时针搅打至吸收；或加皮冻。

**Q: 煮饺子为什么要点冷水？**
A: 控制水温，避免剧烈沸腾煮破饺子；同时使馅料均匀受热。
