# 炒青菜

## 快速信息
- 分类：食谱
- 难度：简单
- 时间：5 分钟
- 份量：1-2 人份

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：青菜（油菜/青菜）（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
炒青菜的关键是**大火快炒**，保持**翠绿色泽**和**脆嫩口感**。

**翠绿原理**：
- 高温短时加热，叶绿素降解少
- 避免长时间加热导致叶绿素变橄榄绿
- 出锅前淋少许油，油膜隔绝氧气

**脆嫩关键**：
- 火大、时间短，细胞壁未充分破裂
- 盐后放，避免过早渗透压导致出水

## 制作步骤
1. **预处理**：青菜洗净，沥干水分。
2. **热锅**：大火热锅，放油，油温 7-8 成（200°C）。
3. **爆香**：下蒜末爆香 5 秒。
4. **下菜**：迅速下青菜，大火翻炒 1-2 分钟。
5. **调味**：最后放盐，翻炒均匀出锅。

## 关键技巧
- **锅要烧透**：火大锅热，才能短时炒熟
- **沥干水分**：下锅前尽量控干，避免油溅、出水
- **盐后放**：早放盐青菜易出水、变黄
- **蒜末最后放**：容易焦，应在青菜下锅前或同时放

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 青菜炒黄了怎么办？ → 火太小或炒太久。下次大火快炒，缩短到 2 分钟内。
  - 出水太多？ → 未沥干、火太小、盐放太早。三点都注意。

## 常见问题
**Q: 青菜炒黄了怎么办？**
A: 火太小或炒太久。下次大火快炒，缩短到 2 分钟内。

**Q: 出水太多？**
A: 未沥干、火太小、盐放太早。三点都注意。
