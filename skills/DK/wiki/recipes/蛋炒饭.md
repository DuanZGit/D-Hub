# 蛋炒饭

## 快速信息
- 分类：食谱
- 难度：简单
- 时间：10 分钟
- 份量：1-2 人份

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：隔夜米饭（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
蛋炒饭追求**粒粒分明**和**蛋香包裹**。

**关键科学点**：
- **隔夜饭**：水分少，淀粉回生，炒时不易粘团
- **大火快炒**：水分快速蒸发，米饭升温均匀
- **蛋液拌饭**：蛋液包裹米粒，形成隔离层，口感更松

**火候控制**：
- 锅要烧到足够热再下油
- 油温高，炒制时间短，米饭才干爽

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 隔夜米饭 | 2 碗 | 主料 |
| 鸡蛋 | 2-3 个 | 增香、包裹 |
| 食用油 | 15ml | 润滑、防粘 |
| 盐 | 3g | 基础调味 |
| 葱花 | 适量 | 增香配色 |

## 制作步骤
1. **准备工作**：隔夜饭打散，鸡蛋打散。
2. **炒蛋**：热锅凉油，油温 6 成（160°C）下蛋液，炒至凝固盛出。
3. **炒饭**：锅中再放少许油，下米饭，大火翻炒 2-3 分钟至粒粒分明。
4. **混合**：倒回鸡蛋，加盐，翻炒均匀。
5. **出锅**：撒葱花，淋少许香油。

## 关键技巧
- **米饭要干**：新鲜米饭水分多，容易烂糊
- **先炒蛋后炒饭**：蛋香更浓，米饭更干爽
- **大火快炒**：缩短加热时间，保持香气
- **盐最后放**：避免过早让米饭出水

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 蛋炒饭为什么粘锅？ → 锅不够热、米饭太湿、火太小。建议大火热锅，用隔夜饭。
  - 如何让米饭粒粒分明？ → 用隔夜饭，炒之前用手打散结块，大火快炒。
