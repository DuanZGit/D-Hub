# 盖浇饭

## 快速信息
- 分类：食谱
- 难度：简单
- 时间：20-30 分钟
- 份量：1-2 人份
- 关键词：主食、盖饭、快手菜、一锅出

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：米饭（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
盖浇饭是将炒好的菜和汤汁直接浇在米饭上，实现“菜饭合一”的快手主食。

**关键要点**：
- **米饭要干爽**：用隔夜饭或米水比控制好
- **菜要有汤汁**：汤汁渗透米饭，增加风味
- **搭配平衡**：荤素搭配，色彩丰富

**常见搭配**：
- 番茄鸡蛋 + 米饭
- 咖喱牛肉 + 米饭
- 麻婆豆腐 + 米饭
- 青椒肉丝 + 米饭

## 制作步骤
1. **准备米饭**：煮好米饭，盛入碗中。
2. **炒菜**：根据所选盖浇菜炒制，保持一定汤汁。
3. **浇汁**：将炒好的菜和汤汁直接浇在米饭上。
4. **点缀**：撒葱花、芝麻等。

## 关键技巧
- **米饭要粒粒分明**：用隔夜饭，或煮饭时水稍少
- **菜要略咸**：汤汁渗透米饭后味道适中
- **汤汁不宜过多**：避免米饭过湿
- **趁热食用**：保持最佳口感

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 盖浇饭的汤汁怎么调？ → 根据菜品调整，一般加少量水或高汤，勾薄芡或自然收汁。
  - 盖浇饭可以提前做吗？ → 菜可以提前做，但米饭最好现煮。菜冷藏后加热即可。

## 常见问题
**Q: 盖浇饭的汤汁怎么调？**
A: 根据菜品调整，一般加少量水或高汤，勾薄芡或自然收汁。

**Q: 盖浇饭可以提前做吗？**
A: 菜可以提前做，但米饭最好现煮。菜冷藏后加热即可。

**Q: 如何让盖浇饭更香？**
A: 用猪油或香油炒菜，最后淋少许热油激香。
