# 披萨

## 快速信息
- 分类：食谱
- 难度：中等
- 时间：45 分钟（含面团）
- 份量：1-2 人份
- 关键词：烘焙、面饼、芝士、拉丝

## 因子分析

- **烹饪方式因子**：烘烤（150–250°C，热辐射+对流，分钟~小时级）：整体均匀升温 + 表面美拉德/焦糖化形成焦壳
- **食材因子**：高筋面粉（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **反应条件**：关键温度 220-250°C（反应激活阈值）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
披萨是意式经典，由面饼、番茄酱、芝士、配料组合，高温烘焙形成焦香面饼和拉丝芝士。

**关键原理**：
- **面团发酵**：酵母发酵产生 CO₂，面饼松软有弹性
- **高温烘焙**：烤箱 220-250°C，面饼快速膨胀、表面焦化
- **美拉德反应**：面饼表面、芝士边缘产生焦香
- **芝士融化拉丝**：马苏里拉芝士加热后拉丝

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 高筋面粉 | 200g | 面饼 |
| 酵母 | 3g | 发酵 |
| 番茄酱 | 50g | 底酱 |
| 马苏里拉芝士 | 100g | 拉丝 |
| 培根/蔬菜 | 适量 | 配料 |
| 橄榄油 | 10ml | 增香 |

## 制作步骤
1. **和面**：面粉+酵母+水+盐，揉成面团，发酵 1 小时至两倍大。
2. **整形**：面团擀成圆饼，用手推成边缘厚中间薄的形状。
3. **涂酱**：面饼抹番茄酱，边缘留白。
4. **撒料**：先撒芝士，再放配料，再撒一层芝士。
5. **烘焙**：烤箱 220-250°C，烤 12-15 分钟至边缘金黄、芝士融化。
6. **出炉**：淋少许橄榄油，撒罗勒叶。

## 关键技巧
- **烤箱要预热**：温度不足面饼不蓬松
- **酱不要太多**：避免面饼湿软
- **芝士分两次撒**：底层融化粘合，顶层拉丝
- **配料不要太多**：避免水分过多，影响脆度

## 预期成品

- **质地**：外脆内嫩（焦壳 + 内部多汁）
- **色泽**：金黄 / 焦糖色
- **风味**：焦香 + 香料渗透味
- **营养保留率**：蛋白质 85–90%

## 安全边界

- 肉类中心温度：禽 74°C+ / 猪 71°C+ / 牛 63°C+
- 锡纸包裹减少表面过度焦化
- 烤箱内禁用普通玻璃容器
- 关键反应温度：220-250°C，避免超温产生有害副产物
- 操作注意：
  - 披萨底部为什么不脆？ → 烤箱温度不够、烤盘太冷、或酱料太多。用高温，烤盘预热，酱料适量。
  - 芝士为什么不拉丝？ → 不是马苏里拉芝士、或温度不够。使用马苏里拉，确保烤箱温度足够。

## 常见问题
**Q: 披萨底部为什么不脆？**
A: 烤箱温度不够、烤盘太冷、或酱料太多。用高温，烤盘预热，酱料适量。

**Q: 芝士为什么不拉丝？**
A: 不是马苏里拉芝士、或温度不够。使用马苏里拉，确保烤箱温度足够。

**Q: 面饼怎么更松软？**
A: 发酵充分、揉面到位、烘焙时高温快速膨胀。
