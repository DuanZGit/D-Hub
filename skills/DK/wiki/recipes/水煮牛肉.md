# 水煮牛肉

## 快速信息
- 分类：食谱
- 难度：中等
- 时间：35 分钟
- 份量：3-4 人份

## 因子分析

- **烹饪方式因子**：煮（100°C，水传导）：水溶性维生素溶入汤中，汤可回收；肉类蛋白质变性凝固
- **食材因子**：牛里脊（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **反应条件**：关键温度 200°C（反应激活阈值）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
水煮牛肉是川菜经典，特点是**肉片嫩滑**、**麻辣鲜香**、**热油激香**。

**肉片嫩滑**：
- 上浆锁水：蛋清、淀粉、油
- 低温滑油或水烫：油温/水温控制在 3-4 成
- 快速成熟，避免过度加热

**热油激香**：
- 最后浇热油，瞬间激发香料香气
- 油温要高（200°C 以上），才能充分激香

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 牛里脊 | 300g | 主料 |
| 豆芽/青菜 | 200g | 垫底蔬菜 |
| 豆瓣酱 | 20g | 咸辣味 |
| 辣椒面/花椒 | 各 5g | 麻辣味 |
| 生抽 | 10ml | 咸鲜 |
| 蛋清、淀粉 | 各 1 个/15g | 上浆 |
| 食用油 | 50ml | 滑油、浇油 |

## 制作步骤
1. **牛肉处理**：切薄片，加盐、蛋清、淀粉抓匀，封油冷藏 20 分钟。
2. **烫蔬菜**：豆芽/青菜焯水，捞出沥干，铺碗底。
3. **滑肉片**：锅中加水或高汤，水沸后转小火，肉片逐片放入，烫至变白捞出，放在蔬菜上。
4. **调味**：锅中放油，下豆瓣酱炒出红油，加辣椒面、花椒、生抽，加热水煮开，过滤倒入碗中。
5. **浇油**：锅中烧热油至冒烟，淋在肉片上，激出香气。

## 关键技巧
- **肉片要薄**：2-3mm，易熟嫩滑
- **上浆要足**：蛋清、淀粉、油都要抓匀
- **最后浇油**：油温要高，香气才充分
- **汤不要多**：碗中汤量适中即可

## 预期成品

- **质地**：软（长时间水煮，细胞壁充分降解）
- **色泽**：清亮汤色
- **风味**：清淡原味
- **营养保留率**：水溶性维生素溶出至汤中（喝汤可回收）

## 安全边界

- 叶菜短时快煮保留色泽
- 肉类彻底煮熟（中心 >70°C）
- 关键反应温度：200°C，避免超温产生有害副产物
- 操作注意：
  - 肉片老怎么办？ → 上浆不足或加热过度。确保低温快熟，变白即捞出。
  - 不够麻辣？ → 增加辣椒面和花椒量，最后浇油前可在肉片上撒干辣椒段。

## 常见问题
**Q: 肉片老怎么办？**
A: 上浆不足或加热过度。确保低温快熟，变白即捞出。

**Q: 不够麻辣？**
A: 增加辣椒面和花椒量，最后浇油前可在肉片上撒干辣椒段。
