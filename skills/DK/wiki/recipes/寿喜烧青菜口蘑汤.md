# 寿喜烧青菜口蘑汤（上海青版）

## 来源
DK 因子模型生成（基于食品化学原理 + 日式寿喜烧调味）

（无外部来源，基于因子模型）

## 基本信息
- 菜品类型：汤 / 日式甜咸底
- 烹饪方式：煮 + 煸
- 难度：★（1/5，最简单）
- 时间：15 分钟
- 份量：2 人份
- 风味：甜咸鲜（寿喜烧风格）
- 采集时间：2026-08-03

## 食材
- 上海青（标准大小，比小青菜大） 2-3 棵（约 200g）
- 口蘑 5-6 个（约 150g）
- 寿喜烧汁 2-3 大勺
- 清水 400-500ml
- 葱花 少许
- 食用油 1 茶匙（煸口蘑用）

## 调料（按使用顺序）
1. 油（煸口蘑用）
2. 寿喜烧汁（开锅后下）
3. 葱花（出锅前撒）

## 可选配料（按家里可能有）
- 鸡蛋 1 个（蛋花 / 蛋液蘸菜）
- 嫩豆腐 半盒
- 昆布 5cm（谷氨酸底）
- 干香菇 2 朵（第二重鲜味）
- 金针菇 1 把（口感层次）
- 姜丝 几片
- 白胡椒粉 少许

## 步骤
1. **处理食材**：上海青洗净，整棵或对半切；口蘑洗净切片（厚 3-4mm）
2. **煸口蘑**：小火热锅，下油，下口蘑干煸 **1-2 分钟到微黄出水**，逼出香气
3. **加水**：倒入清水 400-500ml，大火烧开
4. **调味**：下寿喜烧汁 **2-3 大勺**，搅拌均匀，尝一下调整
5. **烫青菜**：上海青下锅 **30-60 秒**（先茎后叶，或整棵下锅快烫）
6. **组合**：上海青铺碗底，浇入口蘑和汤
7. **点缀**：撒葱花（出锅前）

## 核心原理（因子分析）

### 食材因子
- **上海青**（小白菜 / 瓢儿白）：
  - 水分高（>90%），纤维细
  - 叶绿素丰富，焯烫 30 秒保色
  - 比小青菜大 = 受热面积大，时间略延长
- **口蘑**：
  - 鸟苷酸（GMP）含量高，是天然的鲜味核苷酸
  - 与谷氨酸（酱油/味淋）协同 → 鲜味提升 6-8 倍
  - 加热后菌菇多糖释放 → 汤体变稠、口感顺滑
- **寿喜烧汁**：酱油 + 味淋 + 糖 + 水的甜咸底
  - 酱油：咸 + 鲜（谷氨酸）
  - 味淋：甜 + 鲜（氨基酸）
  - 糖：甜味平衡

### 烹饪方式因子
- **煸口蘑（关键）**：
  - 干煸 → 美拉德反应（150°C+）→ 香气提升
  - 出水 → 菌菇多糖释放 → 鲜味提升
- **煮汤（90-100°C）**：
  - 细胞壁充分破裂 → 鲜味物质释放
  - 蛋白质变性 → 汤色微浊
- **烫青菜（短时）**：
  - 30-60 秒 → 叶绿素保留 80%+
  - 超过 2 分钟 → 维生素 C 流失 >50%

### 调味因子
- **寿喜烧汁**：调味一体化，简化操作
- **寿喜烧汁本身偏咸**：2-3 大勺够 2 人份，先少加再尝
- **葱花出锅撒**：保留葱香（高温会挥发）

## 反应激活
- **鸟苷酸释放**：60°C+ → 鲜味提升
- **谷氨酸 + 鸟苷酸协同**：鲜味提升 6-8 倍
- **叶绿素保留**：30-60 秒烫 → 80%+ 保留
- **美拉德反应**：煸口蘑阶段 → 香气提升

## 预期成品
- **质地**：青菜脆嫩 + 口蘑弹韧
- **色泽**：青菜翠绿 + 汤色淡琥珀
- **风味**：甜咸鲜三重叠加，口蘑鲜味主导
- **营养保留率**：维生素 C 70-80%（短烫）/ B 族 90%+

## 安全边界
- ⚠️ 水量不要太多（400-500ml 即可，太多汤味淡）
- ⚠️ 青菜不要煮太久（30-60 秒，超过 2 分钟维生素 C 流失 >50%）
- ⚠️ 寿喜烧汁先少加再尝（避免过咸）

## 成功关键
- ✅ **煸口蘑是关键**（不去 = 汤寡淡）
- ✅ **青菜短烫**（30-60 秒）
- ✅ **寿喜烧汁先少后多**（先加 2 大勺尝）
- ✅ **葱花出锅撒**（保留香气）

## 常见问题
**Q: 没有寿喜烧汁怎么办？**
A: 替代汁：酱油 2 勺 + 味淋 1 勺（或料酒 1 勺+糖 半勺）+ 糖 半勺 + 水 400ml。比例 4:2:1:汤量。

**Q: 汤太咸/太淡怎么办？**
A: 太咸 → 加热水稀释；太淡 → 再加半勺寿喜烧汁，或加点盐和味精。

**Q: 口蘑可以不放吗？**
A: 不建议。口蘑是这碗汤的鲜味核心，去掉就成普通酱油汤了。

**Q: 上海青可以换成其他青菜吗？**
A: 可以。油菜 / 菜心 / 油麦菜都适合，焯烫时间略调整（菜心 30 秒，油麦菜 45 秒）。
