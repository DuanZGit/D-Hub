# 炝炒牛心菜

## 快速信息
- 分类：食谱
- 难度：简单
- 时间：10分钟
- 份量：2人份
- 口味：香辣清脆

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：牛心菜（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
炝炒是先以花椒和干辣椒炝锅，再用大火快速翻炒蔬菜的烹饪技法。高温使美拉德反应发生，产生焦香气味；花椒中的挥发油释放麻味，干辣椒中的辣椒素提供辣味，三者融合形成独特的"炝"味。

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 牛心菜 | 半个（约300g） | 主料，提供清脆口感 |
| 花椒 | 1小勺 | 炝锅灵魂，提供麻味 |
| 红干辣椒 | 3-5个 | 提供辣味和香气 |
| 食用油 | 2汤匙 | 烹饪介质，传递热量 |
| 味极鲜（生抽） | 1大勺 | 提鲜，调味 |
| 盐 | 适量 | 基础调味 |
| 鸡精 | 少许 | 增鲜 |

## 制作步骤

### 阶段一：准备
1. **牛心菜处理**：手撕成小块，洗净沥干
   - 【原理】手撕断面不规则，比刀切更易入味
   - 【原理】沥干水分避免炒制时出水过多

### 阶段二：炝炒
2. **炝锅**：热锅倒油，放入花椒小火炸香
   - 【原理】低温油释放花椒挥发油中的麻味物质

3. **爆香辣椒**：加入红干辣椒段爆香
   - 【原理】辣椒素溶于油脂，油温升高释放辣味

4. **大火翻炒**：转大火，倒入牛心菜快速翻炒
   - 【原理】大火锁住水分，保持脆爽口感

5. **炒至断生**：炒至菜叶变软但仍保持脆度（约2分钟）
   - 【原理】过度炒制会变软烂，失去脆感

6. **调味**：加入味极鲜、盐、鸡精快速翻匀
   - 【原理】出锅前调味，保留蔬菜原味

7. **出锅**：快速翻匀即可

## 关键技巧
- **大火快炒**：保持牛心菜脆爽口感，是炝炒的核心
- **花椒+干辣椒**：炝炒的灵魂，先炸出香味再下菜
- **手撕比刀切**：断面不规则更易入味

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 为什么我的炝炒牛心菜出水了？ → 1）牛心菜没有沥干水分；2）火候不够大；3）翻炒时间过长。解决方法：确保菜叶干燥，全程大火，快速翻匀即出锅。
  - 花椒要不要吃掉？ → 传统做法是炝锅后捞出花椒不吃，只留麻味。不喜欢麻味可以先捞出花椒再下辣椒。

## 常见问题

**Q: 为什么我的炝炒牛心菜出水了？**
A: 1）牛心菜没有沥干水分；2）火候不够大；3）翻炒时间过长。解决方法：确保菜叶干燥，全程大火，快速翻匀即出锅。

**Q: 花椒要不要吃掉？**
A: 传统做法是炝锅后捞出花椒不吃，只留麻味。不喜欢麻味可以先捞出花椒再下辣椒。

**Q: 可以加蒜吗？**
A: 可以，蒜末在放牛心菜前加入爆香，增加层次感。
