# 宫保鸡丁

## 快速信息
- 分类：食谱
- 难度：中等
- 时间：20 分钟
- 份量：2-3 人份

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：鸡胸肉（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
宫保鸡丁是川菜代表，特点是**荔枝味**（小酸小甜小辣）和**糊辣**风味。

**荔枝味**：
- 糖醋比例约 1:1
- 咸鲜打底，酸甜收尾
- 味型层次丰富

**糊辣味**：
- 干辣椒段用小火慢炒至棕红色
- 产生焦香、微糊的独特风味
- 需控制油温，避免炒糊发黑

| 淀粉 | 10g | 上浆、勾芡 |

## 制作步骤
1. **鸡丁上浆**：鸡胸肉切 1.5cm 丁，加盐、料酒、淀粉抓匀，最后封油。
2. **滑炒鸡丁**：热锅凉油，油温 4 成（120°C）下鸡丁，滑至变色盛出。
3. **炒糊辣**：锅中留底油，小火下干辣椒、花椒，炒至棕红色。
4. **爆香**：下姜蒜、葱白炒香。
5. **合炒调味**：下鸡丁、花生米，淋入味汁（生抽+醋+糖+淀粉水），快速翻匀。

## 关键技巧
- **鸡丁上浆**：保持嫩滑，锁住水分
- **小火炒干辣椒**：炒至棕红色即可，过黑发苦
- **花生米最后放**：保持酥脆
- **味汁提前调好**：避免手忙脚乱

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 鸡丁老怎么办？ → 上浆要足，滑油温度不要太高（120-140°C），时间要短。
  - 干辣椒炒糊发黑？ → 一定要小火，炒到棕红就停，余温会继续加热。

## 常见问题
**Q: 鸡丁老怎么办？**
A: 上浆要足，滑油温度不要太高（120-140°C），时间要短。

**Q: 干辣椒炒糊发黑？**
A: 一定要小火，炒到棕红就停，余温会继续加热。
