# 炒面

## 快速信息
- 分类：食谱
- 难度：简单
- 时间：15 分钟
- 份量：1-2 人份
- 关键词：主食、面食、快炒、干香

## 因子分析

- **烹饪方式因子**：炒（200–300°C，油传导，秒~分钟级）：激活美拉德反应 + 表面蛋白快速变性锁水；蔬菜细胞壁部分破裂保持脆度
- **食材因子**：面条（蛋白质/水分/纤维含量决定切配和火候，按实际选料判断）
- **调味因子**：盐缩短接触时间（减少渗透压失水）/ 生抽沿锅边淋入（140°C+ 美拉德锅气）/ 增鲜剂出锅前放（>120°C 降解）/ 香料出锅前保留挥发香气 → 详见 [[调味料下锅时机]]

## 核心原理
炒面是将煮熟的面条与配菜、调料一起快炒，使面条干香、配菜入味，是中式、日式、东南亚常见主食。

**关键要点**：
- **面条要煮到八成熟**：保留弹性，炒时不易碎
- **过冷水**：去除表面淀粉，防止粘连
- **大火快炒**：高温使面条脱水，形成干香口感

**常见类型**：
- **中式炒面**：酱油调味，配菜丰富
- **日式炒面**：酱汁调味，偏甜
- **炒乌冬**：口感 Q 弹，配菜简单

## 关键食材
| 食材 | 用量 | 作用 |
|------|------|------|
| 面条 | 200g | 主料 |
| 配菜 | 100-150g | 蔬菜、肉类 |
| 酱油/酱料 | 20ml | 调味 |
| 食用油 | 15ml | 润滑、防粘 |

## 制作步骤
1. **煮面**：水沸下面，煮至八成熟，捞出过冷水，沥干。
2. **炒配菜**：热锅凉油，下蔬菜、肉类炒至变色。
3. **炒面**：加入面条，大火翻炒 2-3 分钟。
4. **调味**：加酱油、盐等，翻炒均匀。
5. **出锅**：撒葱花、芝麻。

## 关键技巧
- **面条要沥干**：避免炒时出水
- **大火快炒**：保持干香，避免湿黏
- **酱油分次加**：避免过咸，均匀上色
- **配菜先熟**：肉类先炒，蔬菜后放，保持脆度

## 预期成品

- **质地**：脆嫩/嫩滑（短时高温，细胞壁未充分降解或蛋白未过度变性）
- **色泽**：美拉德褐 / 蔬菜翠绿
- **风味**：鲜 + 锅气
- **营养保留率**：维生素C 70–80%，蛋白质 90%+

## 安全边界

- 油温 < 烟点（>180°C 产生有害 PM2.5）
- 翻炒时间：蔬菜 < 2 分钟，肉类 < 3 分钟
- 不粘锅涂层温度 < 260°C
- 操作注意：
  - 炒面为什么粘锅？ → 面条未沥干、火太小、或油不够。确保沥干，大火热锅，油足。
  - 炒面怎么更干香？ → 用干面条、煮后过冷、大火快炒、酱油沿锅边淋入。

## 常见问题
**Q: 炒面为什么粘锅？**
A: 面条未沥干、火太小、或油不够。确保沥干，大火热锅，油足。

**Q: 炒面怎么更干香？**
A: 用干面条、煮后过冷、大火快炒、酱油沿锅边淋入。

**Q: 炒面容易碎？**
A: 面条煮太软、翻炒过度。控制煮面时间，翻炒轻柔。
