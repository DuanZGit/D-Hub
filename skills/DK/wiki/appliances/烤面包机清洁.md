# 烤面包机清洁

## 快速信息
- 分类：家电清洁
- 难度：简单
- 频率：每次使用后 + 定期深度清洁
- 清洁用品：白醋、小苏打、洗碗布

## 核心原理
烤面包机内部容易积累面包碎屑和油脂，长期不清理会冒烟、产生异味，甚至引发安全隐患。

## 基础清洁
1. **倒出碎屑**：拔掉电源，将烤面包机倾斜对着垃圾桶，轻敲背部抖落碎屑
2. **取下架子和托盘**：滑出烤架和底部接屑盘，用水冲洗
3. **内部擦拭**：用非毒性多功能清洁剂喷在海绵上（不要直接喷内部），擦拭内壁和底部
   - 【注意】不要擦拭加热元件（通常在背部）
4. **自然干燥**：清洁后保持门打开，让内部风干
5. **玻璃门清洁**：白醋+水 1:1 混合液擦拭
6. **外部清洁**：
   - 玻璃门：喷玻璃清洁剂或多功能清洁剂，干布擦拭
   - 喷漆钢/塑料外壳：湿布蘸肥皂水擦拭
   - 镀铬外壳：超细纤维布擦干

## 深度清洁（顽固污渍）
1. **清除易去除的污渍**：用海绵+清洁剂擦拭内壁
2. **小苏打去顽固污渍**：
   - 配方：3 汤匙小苏打 + 1 汤匙氨水 → 糊状
   - 涂在海绵上，以画圈或之字形擦拭污渍区域
   - 替代配方：1 汤匙柠檬汁 + 2 汤匙奶油 tartar
3. **擦拭油脂**：湿布撒小苏打粉，擦拭内部油腻表面
4. **尼龙刷清除焦化物**：对于烧焦的黑色/棕色食物残渣，用蘸肥皂水的尼龙刷清理
5. **加热元件清洁**：
   - 用布清洁加热元件
   - 如有残留，用 1 汤匙小苏打 + 1 汤匙水调糊，涂在元件上
   - 用牙刷轻轻刷洗，**不要用力刮擦**
   - 【重要】使用前彻底刷洗干净，否则残留物会再次燃烧

## 预防保养
1. **频繁轻度清洁**：发现小滴油脂或碎屑立即用湿布擦拭
2. **需要时深度清洁**：看到或闻到冒烟、食物粘在内壁上时进行深度清洁
3. **不要在烤面包机上放东西**：加热时包装袋颜色会转移，甚至熔化
   - 可用卸甲水擦除塑料袋染色痕迹
4. **使用烤箱衬垫**：在底部放一块耐高温不粘衬垫，减少接屑盘清洁频率

## 常见问题

**Q: 两层玻璃之间的碎屑能清理吗？**
A: 如果有较大缝隙，可用罐装空气吹出，或用 chopstick/skewer 推出。

**Q: 热的時候能清洁吗？**
A: 绝对不能！必须拔掉电源并完全冷却后再清洁。
