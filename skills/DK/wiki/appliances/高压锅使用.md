# 高压锅 / 电压力锅使用

> 来源：HowToCook [tips/learn/高压力锅.md](https://github.com/Anduin2017/HowToCook)（Unlicense 公共领域） · DK 语料 `raw/howtocook-tips/2026-09-13-高压力锅.md`


## 快速信息
- 分类：厨具 · 使用指南
- 原理：蒸汽积聚提高锅内压力 → 水的沸点超过 100℃ → 缩短烹饪时间
- 来源：HowToCook tips/learn · 2026-09-13

## 优点
- 实际烹饪温度更高，**大幅缩短时间**
- 高温促进褐变与焦糖化，产生炖锅做不出的风味
- 蹄筋类结缔组织在高压下容易煮烂，口感好

## 流程
1. 食材与水入内胆，合盖，**确认锅体密封**
2. 加热。自锁阀（浮子阀）随压力升高锁闭 → 增压；它同时锁住锅盖防强开
3. 蒸煮时**确认自锁阀不被异物遮挡**
4. 转保温后，**用排气阀把蒸汽排空才能开盖**
5. 气压与外界平衡后自锁阀自动松开 → 这是"能开盖"的判断标志

## ⚠️ 安全（错误代价：烫伤 / 爆炸风险）
- **蒸汽很烫，不要凑到排气阀上**
- **流质食物不要手动排气**，会喷溅 → 先把食材装密封罐/真空袋再压
- 开盖不要一次全开，**尤其不要对着人正面开盖**；从侧面开盖更安全
- 汤类手动放气可能影响味道与口感
- 密封靠锅盖里的橡胶圈：老旧锅要**检查密封圈是否仍有效、是否完全干净**，任何微粒卡住都会破坏密闭
- 有安全线的不要超线；没安全线的**水位不超过锅体 2/3** → 食材液体过多会堵塞排气阀
- **不要压燕麦、挂面等易起泡食物**，泡沫会阻塞蒸汽阀和泄压管
- 压力阀喷蒸汽/冒烟 = 内部过度加压。此时**减小火力**（风味有损失，且部分机型卡槽可能弯曲）
