# 炒

## 快速信息

- **烹饪方式**：高温油脂传导
- **温度**：200-300°C
- **时间**：1-3 分钟
- **营养保留率**：70-80%
- **健康等级**：★★★☆☆

## 核心原理

200-300°C 高温快速加热，美拉德反应产生香味，快速锁住水分。蔬菜细胞壁快速破裂，释放营养。中餐爆炒、泰式炒河粉、日式炒面都证明大火快炒是关键。

## 科学原理

| 原理 | 说明 |
|------|------|
| 美拉德反应 | 140°C+ 氨基酸+还原糖→香味物质 |
| 细胞壁破裂 | 高温使植物细胞壁果胶分解 |
| 水分锁定 | 快速加热使表面蛋白质凝固 |
| 油烟产生 | 油温>180°C 产生油烟（有害） |

## 炒的技巧

| 技巧 | 效果 | 原理 |
|------|------|------|
| 锅热油热 | 防粘锅 | 油膜隔离食材与锅底 |
| 大火快炒 | 锁住水分 | 表面快速凝固 |
| 食材切小均匀 | 受热一致 | 减小热传导距离 |
| 先炒硬的後炒软的 | 成熟一致 | 不同食材导热速度不同 |
| 开抽油烟机 | 减少油烟吸入 | PM2.5 有害健康 |

## 油烟与健康

| 油温 | 状态 | 产物 | 健康影响 |
|------|------|------|---------|
| <120°C | 安全 | 无 | 无危害 |
| 120-180°C | 警戒 | 少量醛类 | 注意通风 |
| >180°C | 危险 | 大量PM2.5 | 致癌风险 |

## 实操补充（HowToCook）

> 来源：HowToCook [tips/learn/学习炒与煎.md](https://github.com/Anduin2017/HowToCook)（Unlicense 公共领域） · DK 语料 `raw/howtocook-tips/2026-09-13-学习炒与煎.md`

- **金属锅不粘的三种做法**：
  - *先炒鸡蛋法*：炒任何菜之前先炒个鸡蛋，炒完不刷锅，接着炒下一样就不粘
  - *热锅凉油法*：空锅干烧受热均匀 → 放凉油转满锅 → 冒气体即油已热 → **把油倒出不刷锅**；重复 2–3 遍效果更好
  - *热锅双油法*：热锅 → 放**少量**凉油转满锅 → 冒气后再加凉油直接开炒
- 判断锅/油热否：手掌平放锅上方感受热量；**油热后才放食材**
- ⚠️ **倒油前务必确认锅内无残水**；食材要沥干、必须完全解冻 → 水遇热油飞溅会烫伤
- ⚠️ **油锅起火切不可倒水灭火**（会使火势扩大）。火刚起时：迅速关火 + 盖上锅盖
- 不粘锅靠内壁涂层，**金属锅铲会划伤涂层** → 用木制或硅胶锅铲
- 不建议用铝制容器，见 [[家庭食品安全]]
- **辅料下锅顺序**：姜（含水最多，需要时间煸出汁）→ 葱/蒜/辣椒 → 干料（八角花椒）→ 干辣椒（最后，几秒即黑）。炒菜可先下干料给油增香；炖焖菜不要，翻炒太久干料会发黑发苦。小火炒到金黄的香气是调料给不了的
- **放盐时机与盐量**（150g 级家庭量好记）：
  | 场景 | 时机 | 盐量 |
  |------|------|------|
  | 快炒 | 先加盐 | 食材总重 × 0.9% |
  | 肉食 | 八成熟 | （食材总重 + 30ml 汁水）× 1–1.2% |
  | 汤 | 最后加 | 最初水量 × 0.8% |
  一天总盐量建议不超 5g（WHO 口径）
