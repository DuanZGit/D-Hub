# 腌

## 快速信息
- 分类：烹饪技巧
- 难度：简单
- 时间：30 分钟-数天
- 关键词：腌制、入味、去腥、嫩化

## 核心原理
腌是将食材与盐、糖、调味料、酸性物质等混合，通过渗透、发酵或酶解，使食材入味、去腥、嫩化的预处理方法。

**主要类型**：
- **干腌**：盐、糖、香料直接涂抹
- **湿腌**：盐水、酱汁浸泡
- **酸性腌**：醋、柠檬汁、酒腌制
- **酶解腌**：菠萝汁、木瓜汁含蛋白酶

**原理**：
- **渗透**：盐分进入食材，水分排出
- **蛋白质变性**：盐和酸使蛋白质变性，肉质变嫩
- **去腥**：盐、酸、酒溶解异味物质
- **入味**：调味料渗透

## 适用场景
- **肉类**：猪肉、鸡肉、牛肉，腌制去腥增味
- **蔬菜**：泡菜、酸菜，乳酸菌发酵
- **海鲜**：酸腌鱼、醋腌虾

## 常见问题
**Q: 腌肉要不要放盐？**
A: 要，盐帮助入味和蛋白质变性，但量不宜过多。

**Q: 腌制时间多长合适？**
A: 肉类 30 分钟-数小时；蔬菜数小时-数天；根据食材和大小调整。

**Q: 腌肉为什么会出水？**
A: 渗透压作用，盐使细胞脱水，是正常现象。

## 实操补充（HowToCook）

> 来源：HowToCook [tips/learn/学习腌.md](https://github.com/Anduin2017/HowToCook)（Unlicense 公共领域） · DK 语料 `raw/howtocook-tips/2026-09-13-学习腌.md`

> 指烹饪前的**上浆入味**，不含咸肉/香肠那类成品腌制。

- **两条基本权衡**：肉量越大、体积越大、口味越重 → 用料越多；**计划腌的时间越长 → 用料越少**
- **手法按尺寸分**：细肉丝薄肉片要轻（手指呈钳形轻抓、单向搅匀）；肉块同法可稍用力；鸡腿鸡翅先改花刀或扎对穿孔再入料碗裹匀；羊腿在厚处扎对穿孔后涂抹
- **容器与时间**：开口碗盘 0.5–2 小时；食品密封袋封口腌 4 小时–隔夜（**封口要减量用盐**，否则成菜过咸）
- **油封**：腌渍时加适量油锁水，开口长时间腌制尤其需要；油封后炒制要**相应减少底油**
- **料酒不是万能的**：味道浓、容易盖掉食材本香。鸡肉可用白酒替代；牛肉用姜葱水；**白鱼洗净血丝粘膜即可，建议不加**
- 生粉（淀粉）是上浆关键，越要滑嫩用越多；玉米/土豆淀粉粘性最大，红薯淀粉略低。做炸衣时另加，不放腌料里
- 十三香/五香粉辨识度高，**控量**；孜然、小茴香用磨粉不用颗粒（更好入味）

### 通用腌渍公式（一人份 150g）

| 肉类 | 基础 | 常见变化 |
|------|------|---------|
| 牛肉（洋葱炒牛肉） | 生抽 10ml + 料酒 5ml + 白糖 2.5–10g + 生粉 10–15g + 油 10ml | 孜然粉 5g；可加十三香 1g、黑胡椒 1g。**慎用葱姜** |
| 牛肉（蚝油牛肉） | 生抽 5ml + 料酒 5ml + 蚝油 10–20ml + 白糖 5–15g + **生粉 25–35g** + 油 10ml | 上浆感足、偏甜 |
| 鸡肉（五香盐酥鸡，切骰子） | 生抽 10ml + 料酒 2.5ml + 五香粉 5g（或十三香 2.5–5g） | 可加孜然粉 1g、白胡椒 1g |
| 鸡翅中 250g（蜜汁烤） | 划花刀：生抽 10ml + 料酒 2.5ml + 白糖 5–15g + 蜂蜜 10–20ml | 五香粉 2.5g，**不可用十三香** |
| 白色鱼肉 | 盐适量 + 料酒/黄酒少量 | 海鲜酱/蒸鱼豉油；葱姜水 |
| 猪肝 | 生抽适量 + 料酒适量 | 生粉 + 老抽适量（滑炒猪肝） |


## 《料理实验室》数据（盐腌/brine）
- 盐水实验（P279–280）：10–15 分钟放出水 → 40 分钟重吸收 → >40 分钟全块入味
- 抹盐过夜（表面失水 ~5%）煎后多 2% 水分、颜色变深
- 干式盐脆家禽：抹盐裸放 12h+（P567）
- 液体 brine 适合厚块（整鸡/火鸡）；见 [[盐腌与渗透压]] 卡
