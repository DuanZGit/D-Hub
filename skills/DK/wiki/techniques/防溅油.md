# 防溅油（高温下液体调料的爆油风险）

## 快速信息
- 分类：烹饪技巧 / 安全
- 难度：必知
- 关键词：爆油、溅油、烫伤、液体调料、防溅

## 核心原理

**油爆的本质**：高温油（>150°C）+ 含水液体（醋/料酒/酱油/水）接触 → 液体里的水分急剧汽化（体积膨胀 1700 倍）→ 油膜炸开 → 油滴飞溅。

**为什么猛**：
- 油水不互溶（密度差大），水分沉入油底急剧升温
- 100°C 水的汽化潜热高达 2260 kJ/kg
- 一汤匙水（约 15ml）瞬间变成 17 升蒸汽
- 油膜被蒸汽冲破 → 油花四溅

**溅油强度**：
| 油温 | 溅油强度 | 描述 |
|------|---------|------|
| 120-150°C | 轻微 | 少量气泡，不会溅 |
| 150-180°C | 中等 | 明显油花，可能溅到锅边 10cm |
| 180-220°C | 强 | 油花飞溅 20-30cm |
| >220°C | 极强 | 油花飞溅 40cm+，可能灼伤 |

## 易爆油的液体调料

| 调料 | 含水量 | 风险等级 | 备注 |
|------|--------|---------|------|
| 醋 | ~90% | **极高** | 烹醋时最常见 |
| 料酒 | ~70% | **高** | 比米酒水少但仍危险 |
| 生抽 | ~70% | **高** | 淋入时油飞溅 |
| 老抽 | ~70% | **高** | 同上 |
| 啤酒 | ~90% | **极高** | 啤酒鸭风险大 |
| 水 | 100% | **极高** | 不要往热油里直接倒水 |
| 蚝油 | ~60% | 中 | 浓稠，不易溅 |

## 正确做法（防溅 4 步）

### 1. 离火降温
- 爆香料后**关火或离火 5 秒**
- 油温从 200°C → 150°C 以下
- 150°C 油溅油强度从"强"降到"轻微"

### 2. 离火状态下淋
- **不要**在炉子上直接淋入
- 锅离开火源，再缓慢沿锅边淋入

### 3. 立刻下主菜
- 重新开火后**立刻下大量食材**
- 食材水分大量入锅会被分散，不会集中爆
- 这是"以量分散"的安全策略

### 4. 站位 + 防护
- 站**锅侧面**，不要俯身（俯身 = 油溅脸上）
- 准备湿毛巾
- 戴围裙（最好长袖）
- 不要凑近看

## 错误示例（实测伤害）

**2026-08-03 用户实测**：
- 状态：200°C 油锅里刚下干辣椒花椒爆香
- 操作：直接沿锅边淋醋
- 结果：油花四溅，溅到手臂/衣服
- **问题**：200°C 高温 + 俯身 + 沿锅边（不是离火）

## 常见问题

**Q: 为什么菜谱都写"沿锅边淋入"还是会溅？**
A: "沿锅边淋入"是相对安全的（避开油面中心最热点），但**没消除**风险。油温 >180°C 时即使沿锅边也会溅。关键还要**离火**。

**Q: 鲁菜/京菜"烹醋"技法怎么做的？**
A: 厨师手法稳 + 油温控制在 150-170°C（不会到 200°C）+ 沿锅边**非常缓慢**地倒入 + 立刻下菜。家用灶火难以精准控制，**保守做法是离火**。

**Q: 小孩或宠物在厨房怎么办？**
A: 烹醋/料酒/酱油时**必须**远离。可暂时关火等家人离开再操作。

**Q: 油溅到皮肤怎么办？**
A: 立即冲冷水 15-20 分钟（不要涂牙膏/酱油），严重就去医院。

## 替代方案（避溅技巧）

| 场景 | 替代方案 |
|------|---------|
| 烹醋 | 醋跟食材一起下（量大分散） |
| 烹料酒 | 料酒杯靠近锅沿 + 缓慢倒 + 离火 |
| 加酱油 | 沿锅边**非常缓慢**地倒 + 立刻下主菜 |
| 加水 | 沿锅边缓慢倒 + 立刻有食材压住 |

## 安全边界

- ⛔ 油温 >180°C 时**禁止**直接淋液体调料
- ⛔ 俯身向锅内操作
- ⛔ 手放在锅上方（即使戴手套也会烫穿）
- ✅ 站锅侧面
- ✅ 离火操作
- ✅ 食材量大分散
