# 凉拌

## 快速信息
- 分类：烹饪技巧
- 难度：简单
- 时间：5-15 分钟
- 关键词：冷菜、调味、清爽、开胃

## 核心原理
凉拌是将食材焯水或直接生切，加入调味料拌匀的烹饪方法，突出清爽、开胃的特点。

**主要类型**：
- **生拌**：直接生切，如凉拌黄瓜
- **焯水拌**：沸水焯烫后冷却，如凉拌菠菜
- **腌制拌**：盐腌后挤水，如凉拌番茄

**调味原则**：
- **酸**：醋、柠檬汁，开胃解腻
- **甜**：糖、蜂蜜，平衡酸味
- **咸**：盐、酱油，基础味
- **香**：香油、蒜末、香菜，增加香气
- **辣**：辣椒油、芥末， optional

## 操作要点
1. **食材处理**：洗净、切配均匀
2. **焯水（如需）**：沸水下锅，时间短，捞出冷却
3. **挤干水分**：蔬菜焯水后挤干，避免稀释调味
4. **调味拌匀**：调味料先调匀，再与食材拌匀

## 常见问题
**Q: 凉拌菜为什么出水多？**
A: 蔬菜未挤干、盐放太早、或调味料太稀。预先挤干，盐后放。

**Q: 凉拌菜怎么更入味？**
A: 腌制 10-15 分钟，让调味料渗透；或加少许糖促进渗透。

**Q: 凉拌菜可以提前做吗？**
A: 可以，但绿叶菜易出水，建议现做现吃。根茎类可提前腌制。

## 实操补充（HowToCook）

> 来源：HowToCook [tips/learn/学习凉拌.md](https://github.com/Anduin2017/HowToCook)（Unlicense 公共领域） · DK 语料 `raw/howtocook-tips/2026-09-13-学习凉拌.md`

- 凉拌的价值：**不需要热源**、**少洗锅**、**保留食材原始状态**（蔬菜的脆、生肉的质感）
- 两种形态：辅料与食材**交混**，或**分立**（分立时辅料即蘸料）
- 要加大主料与辅料接触面积 → 拍碎、切片、搅碎优于切大块。黄瓜用刀面拍碎（怕飞溅就装食品级袋里拍）
- 常用尺寸：叶菜撕/切 4cm×4cm 或 0.5cm 条；块茎类 0.5cm 截面条或 <0.5cm 厚片；菌类同
- ⚠️ **猪肉与禽肉必须十成熟、完全熟制、不见任何血水**才能凉拌；部分牛肉/鱼/海鲜在确认安全后方可生食 → 见 [[家庭食品安全]]
- 菌类严格确认安全；不确认的食材**不要凉拌**
- 容器用**容积 ≥ 食材两倍**的硬质容器防溅出；在塑料袋/塑料碗里腌过的，尽快转移到瓷或金属容器
- 生食辅料在**洁净砧板**上处理，与熟食分开
