# 面筋形成

## 快速信息
- 分类：食品化学/谷物
- 难度：中等
- 关键词：麸质、面筋、面糊、脆皮、静置
- 来源：《料理实验室》P858 实验「面糊里的麸质生成」、P861 静置实验，置信度：高

## 核心原理
面粉含水 >~30% 时谷蛋白+醇溶蛋白交联成面筋网络。面筋 = 弹性+韧性的来源，但在**裹粉面糊**里是要避免的因子：

- 湿搅越多 → 面筋越多 → 外壳硬韧（裹面的反面结果）
- 正确操作：面糊「刚湿成糊」即停手，允许小颗粒（P858 实验结论）
- 静置（P861 实验）：让淀粉均匀吸水、面筋松弛 → 但别过度（>30 分钟风味与挂性开始下降）

**面包/面饼（相反需求）**：面筋要多 → 充分搅拌/揉捏；司康/比司吉要少（P52「混合面糊」+ P135 泡打粉实验）。

## 关键数据
| 场景 | 面筋策略 |
|---|---|
| 裹粉炸鸡/天妇罗 | 最小化：刚湿即停，双裹替代多搅 |
| 炸鸡更脆（P858 专栏） | 双裹（糊-粉-糊）+ 低温 163°C 级炸熟 + 高温快炸上色 |
| 日式面包糠（P871） | 分形结构=高比表面积 → 同一油温下更脆（形状因子>成分因子） |
| 饼类泡打粉 | 双重作用泡打粉（P135）：低温酸先反应一半、烘烤热反应另一半；小苏打替代需额外酸（酸性奶/柠檬汁） |

## 常见问题
**Q: 挂糊为什么发硬？**
A: 搅出面筋了。面糊拌到「像稀奶油」即停；裹粉类抖掉浮粉直接炸。
