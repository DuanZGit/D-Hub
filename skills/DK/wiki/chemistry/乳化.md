# 乳化

## 快速信息
- 分类：食品物理/调味
- 难度：中等
- 关键词：美乃滋、油醋汁、卵磷脂、破乳、荷兰酱、蛋黄酱
- 来源：《料理实验室》P766/P794–795，置信度：高

## 核心原理
油滴分散进水相 + 乳化剂分子定向排列（亲油尾朝油滴、亲水头朝水）→ 稳定乳液。通用路径：**剪切 + 缓慢加油**。

**乳化剂来源（由强到弱）**：
- 蛋黄卵磷脂（最强，且量大）：一个蛋黄可做 ~3.8 升（1 加仑）美乃滋——美乃滋便宜的物理原因
- 芥末（亲水胶体，辅助稳定）
- 全蛋 > 蛋黄单独 > 无蛋（纯大豆卵磷脂替代品）

## 关键数据
| 项 | 值 |
|---|---|
| 一个蛋黄乳化油量 | ~3.8 L 美乃滋 |
| 荷兰酱黄油条温度 | 93.3°C 滴入 |
| 荷兰酱成品区间 | 71.1~82.2°C |
| 荷兰酱翻车点 | <35°C 黄油固相脂肪破坏乳化剂 |
| 破乳修复 | 「糊状」阶段后加一点水→恢复→继续加油 |

## 应用要点
- 油醋汁（P763 三种基本沙拉酱之一）：加芥末或少许蛋黄=乳化强迫症解药（P766）
- 奶酪通心粉回热必破乳（酪蛋白冷却析出无法再乳化）→ 一次做完
- 低温慢煮汉堡/奶烙：蛋黄卵磷脂同时让肉饼「团结」+ 做蛋黄酱基底

## 常见问题
**Q: 美乃滋做成了水油分离怎么办？**
A: 破乳了——另起一小勺蛋黄/芥末，把破掉的水油液流一点一点打进去（加水可救回）。
