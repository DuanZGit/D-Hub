# 美拉德反应

> 食品烹饪中最重要的化学反应之一，产生褐色物质和香味物质。

## 快速信息

| 项目 | 内容 |
|------|------|
| 英文名 | Maillard Reaction |
| 分类 | 褐变反应 |
| 温度范围 | 140-165°C |
| 反应物 | 氨基酸 + 还原糖 |

## 反应机理

### 1. 缩合反应
氨基酸与还原糖缩合生成席夫碱

### 2. Amadori重排
席夫碱经Amadori重排生成Amadori产物

### 3. 脱水裂解
Amadori产物经脱水、裂解生成多种中间产物

### 4. 聚合反应
中间产物进一步反应生成褐色物质和香味物质

## 生成物

### 有益产物
| 产物 | 特性 | 作用 |
|------|------|------|
| 类黑精 | 褐色色素 | 强抗氧化 |
| 呋喃类 | 焦糖香 | 增香 |
| 吡嗪类 | 坚果香、烤香 | 增香 |
| 噻吩类 | 肉香 | 增香 |

### 有害产物
| 产物 | 产生条件 | 风险 |
|------|---------|------|
| 丙烯酰胺 | 淀粉类>120°C | 可能致癌 |
| 杂环胺 | 肉类高温 | 可能致癌 |
| 多环芳烃 | 明火烤制 | 可能致癌 |

## 感官影响

### 颜色变化
```
白色 → 浅黄 → 深黄 → 褐色 → 深褐色
```

### 风味变化
- 烤香
- 焦香
- 坚果香
- 肉香

### 质地变化
- 表面变脆
- 形成硬壳

## 烹饪应用

### 促进方法
| 方法 | 原理 |
|------|------|
| 高温（140-165°C） | 提供足够能量 |
| 碱性环境 | 加速反应 |
| 低水分活度 | 减少水解 |
| 适当时间 | 充分反应 |

### 抑制方法
| 方法 | 原理 |
|------|------|
| 酸性环境 | 减缓反应 |
| 低温 | 能量不足 |
| 高水分活度 | 促进水解 |

## 实例应用

### 煎牛排
- 温度：200°C以上
- 时间：每面2-3分钟
- 结果：表面褐色，内部粉红，香味浓郁

→ 详见 [[煎牛排]]

### 烤面包
- 温度：180-200°C
- 时间：20-30分钟
- 结果：表面金黄，香气四溢

→ 详见 [[烤面包]]

### 炒洋葱
- 温度：150-180°C
- 时间：10-15分钟
- 结果：焦糖化，甜味增加

→ 详见 [[炒洋葱]]

### 红烧肉
- 温度：140-160°C
- 时间：炒糖色时
- 结果：酱油与糖反应，增香增色

→ 详见 [[红烧肉]]

## 健康影响

### 正常烹饪
- 产生抗氧化物质（类黑精）
- 增加食物风味
- 提高消化率

### 高温过度
- 可能产生丙烯酰胺
- 可能产生杂环胺
- 可能产生多环芳烃

### 建议
- 避免过度焦糊
- 控制烹饪温度
- 搭配蔬菜水果

## 《料理实验室》数据
- 阈值：**≥148.9°C（300°F）** 以上发生（P21 基准表）；温度、pH、时间、还原糖含量四因子决定强度
- **pH 因子**：同温度下 pH 越高（碱性）反应越强——咖啡烘焙、面包壳同机理（煎烤章「梅纳反应」专栏）
- 牛排：目标核心 54.4°C 三分熟 + 干表面高温锅煎出焦壳（煎烤章·牛排静置段）；静置后再升 ~2.8°C（煎烤章·牛排静置段）
- 蔬菜煎（蔬菜章·煎/炒段）：目的是外表美拉德棕化造风味层次，油温需 >148.9°C
- 160°C 烘烤可"软化筋膜同时触发梅纳"（低温慢烤段）
