# 盐腌与渗透压

## 快速信息
- 分类：食品物理/调味
- 难度：中等
- 关键词：盐水、brine、抹盐、渗透压、保水、嫩度
- 来源：《料理实验室》P279–280 盐水实验、P348「盐水腌肉」专栏，置信度：高

## 核心原理
盐（高渗）→ 肌肉细胞失水 → 盐液溶解肌纤维蛋白（肌球蛋白）→ 液体重吸回 → 蛋白结构改变、持水性增强。
结果链：**盐越久 = 全块入味 + 煎后更保水 + 更嫩**（与「盐只腌表面」的直觉相反）。

## 关键数据（牛排盐水实验，P279–280）
| 时间点 | 现象 |
|---|---|
| 10–15 分钟 | 盐液开始破坏肌肉结构，放出水 |
| 40 分钟 | 大部分水重吸回，蒸发使风味浓缩 |
| >40 分钟 | 盐味进入整块内部（区别于抹盐立即煎=只有表面味） |
| 冰箱静置一夜 | 表面失水 ~5%，煎后反而比立即煎**多 2% 水分**；肉色变深（溶解蛋白散射光不同） |

其他：
- 煎牛排过程失水 >20%（焦脆边缘更多）
- 豆子罐头：盐水浸泡过夜产生良好口感（P205 专栏「如何让豆类罐头变得美味」）
- 蔬菜焯水用大量滚烫盐水（稀释酸度、保色）
- 干式盐脆家禽（P567）：抹盐裸放 12h+ → 皮脱水 → 烤时脆皮（渗透压+干燥双因子）

## 应用要点
- 「有时间就长盐」：抹盐后放冰箱过夜是书中最优解（P280 原文结论）
- 液体 brine（盐水浸泡）渗透更快，适合厚块（火鸡、整鸡）
- 下限：抹盐后 <10 分钟就煎=表面咸+内部生味

## 常见问题
**Q: 抹盐一夜肉不会太咸吗？**
A: 不会——重吸收的是被蒸发稀释的盐液；表面 5% 失水可忽略，内部咸度均匀且可接受（书内结论）。
