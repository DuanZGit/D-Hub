# 蛋白质变性

## 快速信息
- 分类：食品化学
- 难度：中等
- 关键词：蛋白质、加热、凝固、变性

## 核心原理
蛋白质变性是指蛋白质在某些物理或化学因素作用下，其特定的空间结构被破坏，从而导致其理化性质改变和生物活性丧失的过程。

**主要变性因素**：
- **加热**：最常见的方式，使蛋白质分子运动加剧，氢键断裂
- **酸碱度（pH）**：过酸或过碱会改变氨基酸侧链电荷
- **盐浓度**：高盐可破坏水化层
- **机械作用**：搅拌、剪切
- **有机溶剂**：酒精等

**烹饪中的意义**：
- 肉类加热后变硬、凝固，就是蛋白质变性
- 鸡蛋煮熟后由液态变固态
- 豆腐加热后结构改变

## 常见问题
**Q: 蛋白质变性会损失营养吗？**
A: 变性本身不会降低蛋白质的营养价值，只是改变了空间结构，氨基酸组成不变。过度加热可能使某些氨基酸（如赖氨酸）与糖类发生美拉德反应，降低生物利用率。

**Q: 如何避免蛋白质过度变性？**
A: 控制加热温度和时间。例如，煮鸡蛋用中小火，避免高温长时间加热。

## 《料理实验室》数据
- **蛋清分温凝固**（P90 实验）：54.4~60°C 起凝 / 68.3°C 卵转铁蛋白松网 / 82.2°C 主蛋白全凝 / >82.2°C 越热越硬
- **蛋黄**：62.8°C 起凝 → 70°C 结实 → >76.7°C 橡胶化
- 熟成档位：76.7°C 软（卡仕达）/ 82.2°C 坚固有弹性
- 荷兰酱 <35°C 黄油固相会破乳化；成品 71.1~82.2°C 可接受
- 肉纤维蛋白收缩收紧（炖肉 82.2°C 以上反硬因子，炖肉指南·胶原分解段）
