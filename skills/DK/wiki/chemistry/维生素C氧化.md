# 维生素C氧化

## 快速信息
- 分类：食品化学
- 难度：中等
- 关键词：抗坏血酸、氧化、褐变、营养流失

## 核心原理
维生素C氧化是指抗坏血酸在氧气、光照、金属离子或碱性条件下，失去电子转化为脱氢抗坏血酸，进一步水解为二酮古洛糖酸的过程。

**氧化途径**：
1. **酶促氧化**：多酚氧化酶（PPO）催化
2. **非酶促氧化**：氧气直接氧化，光照加速
3. **金属催化氧化**：Cu²⁺、Fe³⁺显著加速

**影响因素**：
- **pH**：碱性条件加速氧化
- **温度**：高温加速反应速率
- **氧气**：切分后表面积增大，氧化加快
- **金属离子**：铜、铁是强催化剂

**烹饪中的表现**：
- 蔬菜切后放置变黄
- 水果切开后褐变
- 果汁久置颜色变深

## 防止方法
1. **隔绝氧气**：真空包装、覆盖保鲜膜
2. **酸性环境**：加少许柠檬汁、醋
3. **低温储存**：冷藏减缓反应
4. **减少金属接触**：用不锈钢刀具
