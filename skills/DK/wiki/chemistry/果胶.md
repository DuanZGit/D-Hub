# 果胶

## 快速信息
- 分类：食品化学/蔬果
- 难度：中等
- 关键词：果胶、保色、焯水、西蓝花、洋葱、炖烂
- 来源：《料理实验室》P115/P126/P132/P173/P350，置信度：中

## 核心原理
果胶 = 黏合植物细胞的「胶水样」碳水化合物。它决定蔬菜两种相反的命运：

- **焯水**：果胶 83.9°C 以下「不会失去作用」（P132）→ 大锅滚烫盐水快焯能保翠绿保脆（焯水法 P442）；60~65.6°C 温段果胶开始起作用/软化（P132）

## 关键数据
| 因子 | 值 |
|---|---|
| 果胶结构保持上限 | 83.9°C 以下不失活（P132 洋葱水冲实验：超过 83.9°C 热水久冲才软化解体） |
| 果胶软化温度 | 60~65.6°C（P132 原句语境：此温段水冲洋葱使果胶开始作用/变软，非果胶胶化温度） |
| 小苏打的作用 | 提高液体 pH → 软化维系西蓝花细胞的果胶，一小撮足够（P115） |
| 洋葱 | 细胞被果胶维系；83.9°C 以下不失活 → 法式洋葱汤靠慢煎脱水而非煮软（P173） |
| 绿色未熟番茄 | 果胶比例高（P173）→ 浓酱/辣酱凝力强，不需另加淀粉 |
| 马铃薯 | 果胶在烹调时解体（P350） |

## 应用要点
- 焯水保翠三要素：大锅（酸度被稀释）+ 滚烫（热冲击）+ 盐水（蔬菜章·焯水保翠段）
- 西蓝花/青花菜：小苏打提 pH（碱性抑制果胶溶化，且抑制叶绿素降解）
- 做果酱/番茄酱：绿色未熟番茄果胶比例高（炖肉章·绿番茄果胶）→ 凝力强
- 炖烂 = 果胶溶解时间：温度越高越慢（炖煮上限 100°C / 盖盖 98.9°C）

## 常见问题
**Q: 焯水蔬菜为什么发黄/发褐？**
A: 酸度高+果胶解体+细胞破裂氧化。大锅盐水稀释酸度是关键修正。
