# 西兰花

## 快速信息

- **分类**：食材 / 蔬菜
- **别名**：青花菜、绿花菜、罗马花椰菜
- **科属**：十字花科芸薹属
- **起源**：地中海东部海岸
- **热量**：~34 kcal/100g
- **维生素C**：51-89mg/100g（极高）

## 核心原理

西兰花是十字花科蔬菜中的营养冠军，富含萝卜硫素（来自葡糖异硫氰酸盐），这是一种被证实具有抗癌活性的植物化学物质。西兰花中的吲哚衍生物可调节雌激素代谢，类黄酮物质调节心血管功能。其维生素C含量远超多数蔬菜，是增强免疫力的天然宝库。

## 烹饪要点

### 最佳烹饪方式

| 做法 | 营养保留率 | 说明 |
|------|-----------|------|
| 蒸 | ~90% | 保留最多维生素C |
| 快炒 | ~80% | 3-5分钟火候控制 |
| 焯水 | ~70% | 水中加盐和食用油保色 |
| 水煮 | ~50% | 水溶性维生素流失严重 |

### 关键技巧

1. **焯水保色**：水中加盐和少量食用油，保持翠绿
2. **面粉水浸泡**：去除杂质和农药残留
3. **控制时间**：快炒 3-5 分钟，避免营养流失
4. **搭配大蒜**：蒜素+硒增强免疫力，保护肝脏

### 经典搭配

- **西兰花炒虾仁**：优质蛋白互补，锌促进维C吸收
- **蒜蓉西兰花**：蒜素+萝卜硫素双重抗癌
- **上汤西兰花**：清淡鲜美，保留营养

## 营养信息

### 健康益处

1. **抗癌**：萝卜硫素阻止早期癌细胞生长
2. **心血管保护**：类黄酮调节血脂
3. **增强免疫**：超高维生素C含量
4. **控制血糖**：膳食纤维延缓糖分吸收
5. **降雌激素**：吲哚衍生物降低雌激素水平

### 适用人群

- 高血压患者
- 糖尿病患者
- 健身减脂人群
- 术后调养人群
- 癌症预防

### 注意事项

- 阴虚火旺者慎食
- 甲状腺问题者注意适量（十字花科含致甲状腺肿物质）
- 避免与松花蛋、咸鸭蛋同食

## 常见问题

**Q: 西兰花怎么炒才不黄？**
A: 焯水时水中加盐和食用油，快炒不超过 3-5 分钟，大火快炒保持脆嫩。

**Q: 生吃西兰花营养更好吗？**
A: 生吃维生素C保留最多，但萝卜硫素需要切碎后静置 40 分钟激活酶。熟食更易消化。

**Q: 为什么西兰花被称为十大健康食品？**
A: 美国《时代》杂志推荐，因其营养全面、抗癌活性强、热量低。
