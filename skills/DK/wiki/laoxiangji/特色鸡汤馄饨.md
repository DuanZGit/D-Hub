# 老乡鸡 · 特色鸡汤馄饨

> 本类烹饪原理 / 预期成品 / 安全边界 / 缩放通则 → 见 [index](index.md#主食)

- 门店批量：主料合计约 3410g → 家庭 2 人份 **×0.18**
- 原文时间：20 分钟、60 分钟、5 分钟

复现依据：配料标注「老乡鸡中央厨房」自产（无零售对应品） · 含复合/预制料：速冻 · 官方未公布配比

## 配料（原文）

- 馄饨（去皮前夹肉、后座肉、清酱汁、淀粉、小麦粉、盐、白砂糖等）（老乡鸡中央厨房和面、拌馅、成型、速冻，详细成分、配比与步骤老乡鸡官方未公布，请依据个人口味适量调整）
- 老鸡汤
- 葱花

## 步骤（原文）

1. 每只鸡用2g 盐均匀揉搓鸡表皮，冷藏20 分钟；
2. 每500g 老母鸡，加入16g 盐，60g 鸡油，2500g 水，烧开
3. 后炖制60 分钟；
4. 取18 个馄饨放入沸水中煮制5 分钟；
5. 舀取350g 老鸡汤倒入面碗，捞起馄饨，沥水后倒入碗中，撒入1g 葱花点缀。
