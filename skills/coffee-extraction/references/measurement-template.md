## 用户口述规则

用户只需口述，不要求手填。已说出的字段直接写入；未说出的字段写「未记录」。

推荐口述顺序：

```text
今天/日期 + 饮品 + 豆子状态 + 粉量 + 研磨 + 出液 + 时间 + 温度 + 压力 + 饮品配比 + 味道 + 喷溅 + 下次感觉
```

示例：

```text
今天热拿铁，18克，研磨2.4/1，91度，出了43克，24秒，压力偏高，奶270克，入口微苦但不涩，后味苦醇，喷溅中等。
```

每次记录后只给一个下一杯变量：

```text
下次只调整：出液 43g → 46g
保持：粉量、研磨、温度、压力和奶量不变
```
