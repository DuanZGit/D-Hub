# 意式咖啡常见问题排障

## 建压慢
1. 检查左侧可变限流阀空放水量（50-100g/10s）
2. 检查右侧 OPV 盲碗压力（10-11bar）
3. 检查预浸泡 P1/P2 时间
4. 检查研磨太粗/粉量不足
5. 检查粉饼结块或通道

## 压力高但流速慢
- 研磨太细
- 粉量过多
- 粉饼太厚
- OPV 调太松

## 压力低流速快
- 研磨太粗
- 粉量不足
- 通道效应
- OPV 调太松

## 无底喷溅
1. 研磨太粗 → 调细
2. 粉量不足 → 增加0.5g
3. 结块 → 用WDT打散
4. 布粉不均 → 找平
5. 粉碗装粉不足 → 增加
6. 手柄密封问题 → 更换密封圈
7. OPV 调太松 → 调至10-11bar
