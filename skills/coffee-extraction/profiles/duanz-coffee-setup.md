# 个人咖啡设备档案 · 断就

## 设备
- **咖啡机**：格米莱 CRM3007Z（震动泵 + 预浸）
- **意式磨豆机**：泰摩 Bricks 01S 积木（约 40mm 锥刀）
- **手摇磨豆机**：Mavo 巫师 Z Pro（2026-08-27 购入，老婆送的）。杯侧当前刻度 6.5。刻度体系未标定，6.5 只作参考记录，不作可复现结论。
- **手冲器具**：聪明杯（新手阶段主力）
- **刻度规则**：2→3 主刻度按 0.2（`2 → 2.2 → 2.4 → 2.6 → 2.8 → 3`）；主格内 `/1` `/2` `/3`；`2.4/3 = 2.6`。整主刻度直接写 `2.4`、`2.6`。
- **空放水量**：80g / 10s（技能参考 50–100g / 10s）
- **盲碗压力**：约 4s 稳定到 10bar
- **粉碗**：双份，基准 18g
- **有 WDT**：是
- **机器侧**：当前标定过关。旧会话「泵老化必换」降为备选，味道问题先走粉饼/配方。

## 研磨字段警告
旧记录 `2.8` / `2.9` 是误把 01S 当成 0–10、每子格 0.1。只能当相对方向（2.9 比 2.8 粗一小格），**不能精确复现**。新记录一律 `2.4/1` 形式。
