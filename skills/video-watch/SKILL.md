# video-watch

模型不能播视频，但能读图。把整段视频按镜头切成若干帧，拼成一张宫格图（每格角标是 `序号 + 时间码`），一次读图就能说出「第几分几秒发生了什么」。

## 一条命令

```bash
vstoryboard "<本地路径 或 https://www.bilibili.com/video/BV...>" --frames 12 --width 420
```

输出两样东西（默认落在 `~/.cache/vstoryboard/<hash>/`）：

- `sheet.jpg` 宫格图 —— 直接 `read` 它
- `shots.md` 清单 —— 每格时间码 + 到下一格的间隔

## 什么时候用哪个参数

| 目的 | 用法 |
|---|---|
| 先摸一遍整条片子 | `--frames 12`（10 分钟以内够用） |
| 片子长 / 想省 token | `--frames 8 --width 360` |
| 要看清楚屏上的小字 | `--frames 9 --width 640` |
| 已知道大概位置，要细看一段 | `--at 01:30 --span 20 --frames 9`（会截那 20 秒） |

单张图约 400–1500 token（取决于格子数与宽度），比逐帧抽图便宜两个数量级。

## 机制（挑帧逻辑）

1. ffmpeg `select='gt(scene,0.28)'` 找镜头切点；
2. 每个镜头起点各取一帧，镜头切换密集的地方帧自然更密；
3. 镜头太少时（访谈、口播、游戏长镜头）在两两间隔最大的地方对半补帧，凑到 `--frames`；
4. 单帧用 `-ss` 精确定位抓，PIL 拼图并烧上角标时间码。

## 边界

- 只有画面：**没有音轨转写**。用户问「他讲了什么」时，B 站视频用 `bili video <BV> [-s]` 拿字幕，或说明只有画面信息。
- 下载走 yt-dlp，B 站免登录最高 1080p（4K/高码率要 cookie）；YouTube 视本机网络可能不通。
- 每次运行都会真实下载视频（缓存在 `~/.cache/vstoryboard`），长片请先用 `--at/--span` 缩小范围。
- 抓帧需要 ffmpeg 与 yt-dlp：`~/.pi/agent/bin/ffmpeg`、`python3 -m yt_dlp`。

## 回答形状

先给时间码定位（「01:46 那格能看清限位器位置」），再说画面里看到什么，最后才结合字幕/常识下判断。画面与字幕冲突时以画面为准，并说明冲突点。
